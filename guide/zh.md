# Hero Wars: Knowledge Engine Bot

你好！这款程序可以为你自动完成 Hero Wars 游戏中的泰坦地牢。你只需要开启它，然后去忙自己的事情 — 它会自己开门、组建队伍并领取奖励。

本指南的编写旨在让任何人都能轻松上手。陌生的词汇我们会立即解释，并在每个章节末尾指引你下一步该怎么做。

## 机器人能做什么

机器人可不是盲目的“连点器”。它像你一样观察游戏屏幕，并自己决定下一步该怎么做。以下是它的功能：

- :eye: **识别屏幕。** 每几分之一秒就会对游戏窗口截屏一次，识别其中的按钮、门和敌人。
- :door-open: **选择门。** 按照你设置的顺序进入房间，并绕过当前有危险的房间。
- :users: **配置阵容。** 每个房间它都有一个“阵容”（我们称之为由五名泰坦组成的队伍）。机器人会自动将泰坦安排到相应位置。
- :heart-pulse: **监测生命值。** 每场战斗后都会读取泰坦的生命值（HP）和能量，并决定阵容是否准备好迎接下一场战斗。
- :swords: **战斗状况不佳时呼叫你。** 此时会弹出«需要干预»窗口：你可以换个阵容重打、接受当前结果或手动通关。如果你离开了电脑，机器人也可以自行决定。
- :chart-no-axes-column: **从战斗中学习。** 记住哪套阵容战胜了哪些敌人，下次会直接使用该阵容。
- :send: **发送 Telegram 消息。** 如果你愿意，它可以在出现异常时以及会话结束时发送总结和警报。

> [!note] 示例：«阿拉吉»带着 36% 的生命值进入战斗，战后掉到了 8%。机器人看到这一点后，明白这场战斗表现不佳，要么询问你，要么自行撤回战斗并换用其他阵容重打。

### 机器人不能做什么

- 它**只通关泰坦地牢**。其他游戏模式它概不熟悉。
- 它**不是“云端游戏”**。游戏在你的 Android 手机上运行，而 Windows 电脑通过 USB 数据线观察手机屏幕并在上面进行点击。手机和电脑缺一不可。
- 它不是魔法师：如果与游戏的连接中断，它会诚实地等待恢复，并向你说明情况。

### 这对账号安全吗？

机器人会尽量像真人一样操作，而不是像个机械人：

- 每次点击都会落在按钮的**随机位置**，而不是同一个点；
- 点击前会留出**反应延迟** — 按钮出现后等待 0.3 至 0.8 秒；
- 它的点击频率**不会超过每秒两次**。

> [!warning] 没有任何程序可以提供百分之百的保证：游戏规则由发行商制定。机器人不会做任何“超出常人速度”的事，但是否使用它依然由你决定。

## 准备工作与安装

这只需要操作**一次**。之后你只需双击启动程序即可。花上大约十五分钟完成这些 — 之后就会变得非常轻松。

### 需要准备什么

- :monitor: **运行 Windows 的电脑。** 程序和机器人都在上面运行。
- :smartphone: **安装了 Hero Wars 的 Android 手机。** 游戏在手机上运行，而电脑观察其屏幕并在上面点击。
- :terminal: **USB 数据线。** 最好是手机平时充电和传输文件用的那根：有些“仅充电”的数据线会导致电脑无法识别手机。
- :folder: **程序压缩包**（`.zip` 文件，里面包含 `HeroWarsBot.exe`）。

> [!note] 游戏依然保留在手机上。机器人不会向手机安装任何多余的东西，也不会读取游戏文件：它只是像你的手指一样观察屏幕并在上面点击。

### 步骤 A。解压程序

1. **解压压缩包** — 右键点击压缩包并选择“全部解压缩…”。选择一个没有俄文字母的简单文件夹，例如 `C:\HeroWarsBot`。
2. **检查文件是否完整** — 文件夹中应该能看到 `HeroWarsBot.exe` 以及其他文件和文件夹。

> [!warning] 请先解压压缩包，然后再运行程序。如果直接从压缩包内部打开 `.exe`，程序的其他文件将无法访问，导致其无法正常工作。

> [!tip] 这个文件夹就是机器人的“家”。在 `HeroWarsBot.exe` 旁边，它会自动生成自己的文件：设置、统计数据、战斗历史。因此请勿将 `.exe` 单独移动，如果要更换位置，请整体移动文件夹。

### 步骤 Б。安装 scrcpy

scrcpy 是一款能在电脑窗口中显示手机屏幕的小程序。机器人正是“观察”这个窗口。随它一起安装的还有 **adb** — 机器人用来在手机屏幕上进行点击的助手工具。

1. **下载 scrcpy** — 在[项目页面](https://github.com/Genymobile/scrcpy/releases)选择适用于 Windows 的最新版本（文件名中带“win64”的 `.zip` 压缩包）。
2. **解压压缩包** — 最好解压到一个没有空格和俄文字母的简单文件夹，例如 `C:\scrcpy`。里面应该包含 `scrcpy.exe` 和 `adb.exe` 文件。
3. **将文件夹添加到 PATH** — 这样 Windows 才知道去哪里寻找这些程序。具体操作方法见下文。

**如何将文件夹添加到 PATH：**

1. **打开设置** — 按 Windows 键，输入“环境变量”，然后选择“编辑系统环境变量”。
2. **找到 “Path”** — 在打开的窗口中点击“环境变量”，在上方的列表中选择 `Path` 行并点击“编辑”。
3. **添加文件夹** — 点击“新建”，输入 `C:\scrcpy`（如果是其他路径请输入你的文件夹路径），然后点击“确定”关闭所有窗口。

> [!note] PATH 是 Windows 在按名称调用程序时搜索的文件夹列表。将文件夹添加到列表中后，就可以在任何地方找到 `scrcpy` 和 `adb` 了。

### 步骤 В。检查 scrcpy 是否安装成功

1. **打开“命令提示符”** — 按 Windows 键，输入 `cmd`，按 Enter。如果窗口在安装前就已经打开，请关闭并重新打开：旧窗口不知道新添加的文件夹。
2. **检查 scrcpy** — 输入 `scrcpy --version` 并按 Enter。应该会显示程序版本号。

如果 Windows 显示“不是内部或外部命令”，而不是版本号，说明文件夹没有成功添加到 PATH 中。请返回步骤 Б，检查 PATH 中填写的文件夹是否包含 `scrcpy.exe`。

### 步骤 Г。设置手机

手机必须允许电脑对其进行控制。这被称为“USB 调试”（为应用开发者设计的模式）。机器人通过它在屏幕上进行点击。

1. **开启开发者模式** — 进入“设置” → “关于手机”，**连续点击 7 次**“版本号”。手机会提示你已成为开发者。
2. **找到“开发者选项”** — 该选项会出现在设置中（有时在«系统»或“高级设置”内部）。
3. **开启两项设置** — “USB 调试”**以及**“USB 调试（安全设置）”。
4. **连接数据线** — 当手机询问“是否允许这台电脑进行 USB 调试？”时，勾选“始终允许”并点击“确定”。

![开启了两个调试设置的“开发者选项”部分](images/usb_debug.png)

> [!warning] 请务必开启**两项**设置。如果只开启第一项，手机画面虽然能传到电脑上，但点击操作无法传给游戏：机器人会一直“点击”，而游戏没有任何反应。

现在我们来测试连接。用数据线连接手机，打开“命令提示符”并输入 `adb devices`。列表中应该会有一行在手机设备号旁边显示 `device` 字样。

- :check: `device` — 一切正常，手机已就绪。
- :triangle-alert: `unauthorized` — 手机正等待你的授权。请查看手机屏幕并点击“允许”。
- :triangle-alert: 列表为空 — 电脑无法识别手机。请尝试更换数据线或更换 USB 接口。

### 步骤 Д。首次启动程序

1. **打开程序文件夹** — 即你解压压缩包的文件夹。
2. **双击 `HeroWarsBot.exe`** — 将打开程序窗口。
3. **熟悉界面** — 左侧是功能区块栏，中间是主页。在连接手机之前，顶部标题栏显示«等待手机» — 这是正常的。

> [!tip] 请始终从程序的文件夹中启动程序（或为 `HeroWarsBot.exe` 创建快捷方式：右键 → “发送到” → “桌面快捷方式”）。这样它才能找到自己的设置和文件。

> [!done] 一切准备就绪：程序已解压，scrcpy 和手机已设置完毕。现在我们来连接手机并开始第一次刷地牢。[下一章节 →](#3)

## Подключаем телефон и первый фарм

现在连接手机并首次启动机器人 — 整个过程大约需要五分钟。首先请记住：显示器上会有**两个窗口**。

- :monitor: **程序窗口** — 即你正在阅读本指南的窗口。里面包含按钮、设置和日志（机器人记录其操作的消息流）。
- :smartphone: **游戏窗口** — 电脑显示器上手机屏幕的“镜像”，名称为 `HeroWarsBot_Arena`。机器人正是“观察”这个窗口。

### 首次启动时主页上有什么

在你自己保存过设置之前，主页（左侧栏的第一个按钮）会显示«从这里开始»卡片，副标题为«3 步 · 约 5 分钟»。

![首次启动：“从这里开始”卡片、红色的“等待手机…”字样以及蓝色的“连接手机”按钮](images/connect_phone.png)

- :smartphone: **«连接手机»** — 标记有«当前»字样。当手机连接成功后，步骤编号会变成绿色对勾。我们现在就来做这个。
- :sliders-vertical: **«检查各房间的阵容»** — «打开 →»链接会跳转到«规则大师»（左侧栏第二个按钮，带有滑块图标）。在那里你将告诉机器人进入每个房间使用哪些泰坦。
- :send: **«为 SOS 设置 Telegram»** — 可选。如果机器人需要帮助，它会通过 Telegram 给你发送消息。

> [!warning] 阵容是首次刷地牢前最重要的设置。机器人会在四个房间（水、土、火和混合）的每一个中使用记录在«规则大师»中的阵容，它无法猜测你的泰坦。如何设置 — 请参阅本指南后面的«规则大师»章节。当你第一次在«规则大师»中保存设置后，«从这里开始»卡片就会消失。

### 步骤 A。连接手机

1. **准备手机** — 用数据线连接手机并解锁屏幕。确保按[第 2 节](#2)所示启用了两个 USB 调试设置。
2. **点击«连接手机»** — 这是右上角的大蓝色按钮。在程序搜索手机时，按钮上会显示«正在连接»。最多可能需要等待 20 秒。
3. **找到游戏窗口** — 将出现一个名为 `HeroWarsBot_Arena` 的新窗口，其中显示手机屏幕。没看到？它可能隐藏在程序窗口后面：请在屏幕下方的任务栏中查找它。
4. **检查标题栏条幅** — 红色的«等待手机»应该变成绿色的«已连接»。而蓝色按钮将变成绿色的«开始刷»。（标题栏是窗口顶部的长条，条幅是带文字的矩形块。）

![手机已连接：绿色的“已连接”字样、“开始刷”按钮以及旁边的游戏窗口](images/phone_connected.png)

窗口没有出现，而日志中提示“Окно scrcpy не появилось или утилита не найдена!”（scrcpy 窗口未出现或未找到工具！）？请按顺序检查：

- :smartphone: 手机屏幕已解锁，数据线插紧。尝试更换其他 USB 接口。
- :terminal: 在命令提示符中，`adb devices` 在你的手机序列号旁显示 `device` 字样。如果显示 `unauthorized` — 请在手机屏幕上允许调试。
- :terminal: 在命令提示符中，`scrcpy --version` 返回了版本号。没有返回？说明 scrcpy 文件夹未包含在 PATH 中 — 请返回[第 2 节](#2)。修改 PATH 后，需要关闭程序并重新打开。

### 步骤 Б。进入泰坦地牢走廊

泰坦地牢是游戏中的一种模式，你需要逐层下潜并在每个房间与敌人战斗。**走廊**是战斗之间的屏幕：上面可以看到带旗帜的门，没有打开其他内容。机器人就是从走廊开始工作的。

1. **打开游戏** — 在手机上启动 Hero Wars 并进入泰坦地牢。
2. **停在走廊界面** — 如果正在进行战斗，请手动打完并关闭结算窗口。需要保持在有门和旗帜的平静界面。

![泰坦地牢走廊：门旁可见旗帜](images/dungeon_corridor.png)

> [!warning] 请勿在战斗途中启动刷地牢。机器人首先会检查屏幕并整理秩序：看到战斗会选择撤退；看到带“再试一次”按钮的结算窗口会取消该战斗并重打该房间；看到阵容选择会完成战斗并立即取消。之后它虽然能继续工作，但你的胜利成果将白白浪费。

### 步骤 В。开始刷地牢

> [!warning] **程序语言必须与游戏语言保持一致。** 带文字的按钮（“攻击”、“确定”、“再试一次”）以及门旁的旗帜，机器人都是通过程序中选择的语言图像进行识别的。这是左侧栏下方带有两个字母（“RU”）的按钮。游戏如果是俄语 — 程序中必须设置为“RU”。如果语言不匹配，机器人将直接找不到按钮。

1. **点击«开始刷»** — 原«连接手机»位置上的绿色按钮。程序会自动调整游戏窗口至所需大小并将其放置在屏幕左上角。
2. **不要被程序窗口消失吓到** — 它最小化到了任务栏，而游戏下方出现了一个狭窄的面板 — **迷你栏**。上面可以看到机器人在做什么。恢复窗口：点击迷你栏上的«展开程序窗口»图标（悬停鼠标会显示提示）或任务栏上的按钮。
3. **观察游戏** — 几秒钟后，机器人会点击门，第一个房间开始。一个房间大约需要半分钟到一分钟。
4. **记住 how 停止机器人** — F10 键可立即停止，F9 键可暂停（机器人会打完当前房间然后等待）。快捷键在游戏窗口或程序窗口处于活动状态时生效。

展开程序窗口，查看日志。每行前面都有时间 — 我们将其省略了。应该会出现以下内容：

- `[УМНЫЙ СТАРТ] Сканирую экран для восстановления контекста...` — 机器人正在观察。
- `[УМНЫЙ СТАРТ] Контекст не требует экстренных действий. Начинаю с HALLWAY.` — 一切正常，它从走廊开始（“HALLWAY”在英语中是“走廊”的意思）。
- `[СТАТИСТИКА] Комнат: 1` — 通关第一个房间。一切正常运行！
- :triangle-alert: `[ВНИМАНИЕ] Окно игры перекрыто (...). Бот ждет фокуса...` — 机器人正在等待游戏窗口重新成为焦点。点击游戏窗口，工作将继续进行。

一分钟过去了，机器人没有任何点击？请检查：

- :gamepad-2: 游戏当前处于泰坦地牢走廊，而不是菜单、商店或战斗中。
- :globe: 程序语言与游戏语言一致（见上方警告）。
- :maximize-2: 游戏窗口完整显示在屏幕上：没有拉伸、没有最大化、没有超出边缘。否则请停止机器人（F10），点击«重置游戏窗口大小»并重新开始。
- :terminal: 日志中没有包含“[ОШИБКА]”的行。如果有 — 我们将在“如果遇到问题”一节中进行讨论。

### 机器人工作期间

- :monitor: 游戏窗口必须保持可见：不要用其他窗口遮挡它，也不要最小化它。如果点击了其他窗口 — 机器人会暂停并等待。
- :smartphone: 请勿关闭游戏窗口或拔掉数据线。如果窗口消失 — 程序会自动停止机器人（“Окно scrcpy закрыто — останавливаю бота”）。
- :maximize-2: 请勿拉伸或最大化游戏窗口：机器人在启动时测量了窗口尺寸，之后一直使用该标准。
- :gamepad-2: 请勿亲自点击手机屏幕：机器人是通过 ADB 进行点击的，你们会相互干扰。如果你想手动操作 — 请将机器人«暂停»（F9），并等待其停在走廊。
- :triangle-alert: 请勿锁定电脑（Win+L）：电脑锁定后机器人看不到屏幕，会一直等待直到你返回。
- :moon: 夜间刷地牢请关闭电脑休眠：在 Windows “设置”中打开«系统» → “电源”，并将屏幕和休眠设置为“从不”。屏幕休眠或熄灭与锁定电脑相同：机器人会停止并等待。菜单名称因 Windows 版本而异。

### 标题栏按钮

右上角条幅旁有三个图标。将鼠标悬停在任意图标上 — 会显示提示文字。

![窗口标题栏：手机条幅、三个按钮和窗口控制按钮](images/header_buttons.png)

- :moon: **«关闭手机屏幕»** — 熄灭手机屏幕，但游戏继续运行，机器人依然能看到一切。夜间非常实用：减少屏幕和电池消耗。程序会将游戏窗口置顶并按下 Alt+O（scrcpy 熄屏快捷键）。要恢复屏幕 — 按手机电源键。迷你栏上也有相同的按钮。
- :refresh-cw: **«重启 scrcpy»** — 关闭游戏窗口并重新打开。如果手机画面卡住，这很有用。仅对程序自己启动的窗口有效。机器人工作时请勿点击：消失的窗口会被程序视为连接中断并停止机器人。
- :maximize-2: **«重置游戏窗口大小»** — 将 `HeroWarsBot_Arena` 窗口恢复为 1606 × 748 尺寸并放置在左上角。这是标准尺寸：按钮搜索正是基于此尺寸配置的。如果拉伸或最大化了窗口 — 请在«开始刷»之前点击此按钮（尽管«开始刷»自己也会执行此操作）。窗口较宽：在 Full HD (1920 × 1080) 显示器上可以完整显示，而机器人仅识别屏幕上的内容。

### 无 Windows 边框的程序窗口

程序窗口没有普通的 Windows 边框，因此在右上角细线后面有它自己的按钮：

- :minus: **«最小化»** — 将窗口隐藏到任务栏。
- :square: **«最大化»** — 全屏显示窗口；之后按钮名称变为«还原»。双击标题栏效果相同。
- :x: **«关闭»** — 关闭程序，如果是程序打开的游戏窗口也会一并关闭。如果机器人正在运行，首先会询问«停止机器人？»；«停止并关闭»按钮会立即停止机器人，且不会将会话总结发送到 Telegram。
- :grip-vertical: **移动窗口** — 按住标题栏：顶部的空白区域或标题。
- **调整大小** — 拖动右下角（三条斜线）。窗口不会变到极小。

> [!note] 请勿混淆«最小化»与«最小化到迷你栏»。«最小化»只是将窗口隐藏到任务栏。«最小化到迷你栏»是机器人工作时主页上的按钮：它还会显示游戏下方的小面板。

> [!done] 手机已连接，机器人已通关第一个房间 — 基础配置完成。接下来我们将了解主页显示的内容以及如何阅读日志。[下一章节 →](#4)

## Главная страница и журнал

主页是左侧栏的第一个按钮，也是你最常看到的页面。它就像汽车的仪表盘：上方是数据（“去哪里”和“怎么走”），下方是日志，机器人会在里面自动记录自己的操作。我们来看看各部分的内容以及如何在日志行中不迷失。

### 顶部的卡片：它会自动改变外观

主页顶部有一张大卡片，但根据机器人当前的状态，它显示的内容有所不同：

- :sliders-vertical: **«启动配置»** — 机器人处于停止状态，但设置已保存。这是“机器人将带着什么去战斗”：目标、模式和阈值。
- :activity: **«当前会话»** — 机器人正在工作。实时数据：收集了多少、通关了多少、消耗了多少时间。
- :file-text: **«会话总结»** — 机器人已停止。卡片显示完成结果以及停止原因。
- :list: **«从这里开始»** — 仅在你一次都没有保存过设置时显示（详见[第 3 节](#3)）。

会话是指机器人从点击«开始刷»到停止的单次运行过程。

### 启动配置

包含四个区块，每个区块回答一个问题。数字取自你的设置，因此如果不满意某些项，请点击卡片右上角的«在规则向导中修改 →»：将打开«规则大师»。

![启动前的主页：“启动配置”卡片和空白日志](images/main_config.png)

- :target: **«本次目标»** — 机器人应该在何时停止。目标**只有一个**：泰坦石、房间数、层数或时间。如果在设置中指定了多项，将按“泰坦石 → 房间数 → 层数 → 时间”的顺序取第一项。如果没有更改 — 目标为 120 泰坦石，约 10–20 个房间。«不限»意味着所有目标均为零，机器人生效直到你手动停止它。
- :shield-check: **«模式»** — 标记有«开»或«关»的«机器人自行决定»区块。开启：战斗表现不佳时，机器人会自动换用备用阵容重打。关闭：它会呼叫你。详情见«规则大师»相关章节。
- :heart-pulse: **«生命值恐慌阈值»** — 例如 40%。如果战后有任何泰坦的生命值低于此值，战斗被判定为不佳。阵容是指由五名泰坦组成的队伍；HP 即生命值。
- :calendar: **«每日重置»** — 例如 05:00。从这个时间开始游戏进入新的一天：机器人开始计算当天的统计数据，并重置昨天的泰坦生命值记录。

> [!note] 机器人**只在你点击«开始刷»时读取一次设置**。在工作过程中进行修改 — 机器人只有在下次启动时才会生效。因此，在机器人工作期间，卡片上显示的是启动时的设置。

### 当前会话

当机器人启动后，卡片变为«当前会话»。右上角显示当前状态：

- :activity: **«正在刷»** — 一切正常，机器人正在工作。
- :pause: **«已暂停»** — 你点击了«暂停»（或机器人自己进入了软暂停）。此时按钮变为«继续»。
- :triangle-alert: **«等待你的决定»** — 屏幕上显示«需要干预»窗口，机器人正在等待回应。
- :refresh-cw: **«正在启动机器人…»** — «开始刷»点击后的前几秒。

![正在刷地牢：带有目标进度条的会话区块](images/main_session.png)

包含四个区块：

1. **«本次泰坦石»** — 机器人收集了多少泰坦石。这是**计数，而不是从屏幕读取**：每个房间 6 个，如果游戏中带“x2”标志则为 12 个。如果目标是泰坦石，旁边会出现“已收集 / 需要”、百分比和进度条。
2. **«已通过层数»** — 当机器人在检查点（每层末尾点击“激活”和“领取”的地方）领取奖励后，该层才被计入。旁边注明了它最后进入的是哪扇门：水、土、火或混合。
3. **«本次战斗»** — 例如“14 场中胜 12 场”。胜利是指通关的房间。撤回是指机器人重打的战斗：重打也算作战斗，因此“总数”可能大于“胜利数”。
4. **«会话时长»** — 时:分:秒，以及小字«每个房间平均 28 秒»。平均值按房间计算，不包含在检查点停留的时间。

> [!tip] 如果目标是房间数或时间，百分比会显示在右侧，形式为“35% / 100”或“35% / 120 分钟” — 因为数字本身放不下目标值。下方进度条作用相同。

> [!note] 达到目标时，机器人不会把一层打到一半就放弃。它会在日志中写入 `[ЛИМИТ] ... Доигрываю этаж и останавливаюсь перед точкой сохранения.`（[限制] ... 打完本层并在检查点前停止。），通关剩余房间并停在检查点前，不会点击“激活”：下次启动时，它首先就会领取本层的奖励。按层数设置目标例外：此时机器人在领取奖励后会立即停止。

### 会话总结

机器人停止后 — 卡片展示总结，窗口会自动从迷你栏展开。上方注明停止的原因：«停止»按钮、scrcpy 窗口被关闭、正常完成工作或机器人自行记录的原因（例如已达到目标）。

![会话总结：停止原因、数据以及“详情”按钮](images/main_summary.png)

与会话中相同的四个区块，但现在是最终数据；在“战斗”中增加了“SOS 窗口数：N”（机器人呼叫你的次数）。**«详情»**按钮会打开包含机器人完整报告的窗口：各阶段平均耗时、用时最长的房间、撤回了多少次战斗以及其中有多少次是机器人**无需你干预**自行完成的。右侧的 ✕ 图标可以隐藏总结，重新显示«启动配置»。点击«开始刷» — 总结会自动消失。

> [!note] 如果配置了 Telegram，在任何正常停止时，总结都会自动发送到 Telegram。«停止»按钮 (F10) 会立即终止机器人，因此这种情况下总结不会发送到 Telegram。

### 日志：里面有什么以及如何阅读

主页下方是**«运行日志»**。机器人会将其每一步操作写入日志，程序会在窗口中进行显示。不要被行数吓到：不需要阅读所有内容，日志仅在出现异常或你感到好奇时使用。

每行的格式完全相同：

`10:26:17.486 [НАВИГАЦИЯ] Двери (слева направо): EARTH (0.98), FIRE (0.97)`

1. **时间** — 灰色显示。时:分:秒和毫秒。
2. **方括号内的标签** — “谁在说话”以及涉及什么事情。带有颜色：颜色提示该行属于日志的哪个类别。
3. **文本** — 发生的具体情况。较长行会自动换行，接续部分会缩进在文本下方，而不是时间下方。

没有标签的行（例如 ` ---> HYPERION: ХП 100%, Энергия 79%`） — 是其上方行的延续，归属于同一个类别。

### “药丸”过滤器

日志上方有五个“药丸”形状的按钮。点击其中一个 — 日志中将仅保留该类别的行。选择会被记住：明天打开程序，依然会选中同一个药丸。

![带有“全部”、“战斗”、“规则”、“系统”和“错误”药丸的日志](images/journal_pills.png)

- **«全部»** — 显示所有内容。
- **«战斗»**（绿色标签） — 通关进度：房间、时间、泰坦生命值、撤回。标签包括 `[КОМБАТ]`、`[СТАТИСТИКА]`、`[ВРЕМЯ]`、`[СОСТОЯНИЕ]`、`[АНАЛИЗАТОР]`、`[ОТКАТ]`、`[ЛИМИТ]`、`[ИТОГ]`。
- **«规则»**（黄色标签） — 机器人的决策：使用什么阵容、为什么撤回战斗、记住了什么。标签包括 `[ТАКТИКА]`、`[КОМАНДА]`、`[ПРАВИЛА]`、`[ОБУЧЕНИЕ]`、`[SOS_CLOSE]`。
- **«系统»**（蓝色标签） — 其他所有内容：走廊和门（`[НАВИГАЦИЯ]`）、启动（`[УМНЫЙ СТАРТ]`）、连接。程序自身的行带有 `[GUI]` 标签显示为灰色，但也归在此处。
- **«错误»**（红色标签） — 所有需要注意的内容：`[ОШИБКА]`、`[ВНИМАНИЕ]`、`[СТОРОЖ]`、`[SOS]`。名称旁标有数字 — 表示累计了多少条此类记录。

> [!warning] “错误”上的红色数字并不总是意味着故障。像 `[ВНИМАНИЕ] Окно игры перекрыто (...). Бот ждет фокуса...` 这类记录也会包含在内 — 机器人只是在等待你将游戏窗口切回前台。请阅读具体文本，不要被颜色吓到。

### 真实日志示例

以下来自机器人真实会话的日志行（为了简短省略了时间）。学会阅读这五条 — 你就能看懂任何日志。

- `[НАВИГАЦИЯ] Выбрана комната EARTH (порядок: water → mix → earth → fire)` — 机器人选择了土门。括号内是你的选门顺序。“Двери (слева направо)”行中的数值表示机器人识别门的置信度（1 表示百分之百确定）。
- `[ВРЕМЯ] Комната 2 (earth): коридор 12.8 с | сборка 3.3 с | бой 8.0 с | результат 9.1 с | всего 33.2 с` — 房间报告：前往门口、配置队伍、战斗和关闭结算窗口各自消耗的时间。
- `[СТАТИСТИКА] Комнат: 3 | Титанит: 36` — 第三个房间通关，收集了 36 泰坦石。这些数字会同步更新到会话区块上。
- `[ТАКТИКА] Откатываю бой сам и переиграю паком [...] (взят: ваш список запасных паков).` — 战斗表现不佳，机器人（«机器人自行决定»模式）正使用备用阵容重打。如果备用阵容成功通关：`[ТАКТИКА] Запасной пак [...] справился. Запоминаю его против этих врагов.`
- `[ОТКАТ] Запускаю протокол отката боя...` — 开始撤回流程：“再试一次” → 暂停 → “撤退”。每出现一条此类记录，在«本次战斗»区块中就会增加一场战斗。

> [!tip] 在每次会话开始时，机器人都会写入 `[ТАКТИКА] Плохой бой: ХП ниже 30% | потеря больше 60% | ...` — 即判定战斗表现不佳的阈值。如果某些地方“出乎你的意料”，请先将该行与你的设置进行对照。

### 日志下方按钮

![日志下方按钮：“保存日志”、“把日志发给作者”、“清空”](images/journal_buttons.png)

- :save: **«保存日志»** — 将整个日志写入文本文件。程序会自动建议文件名 `gui_log_...txt` 和文件夹 `bot_data/logs`；你也可以选择其他位置。
- :mail: **«把日志发给作者»** — 首先会执行相同的保存操作，随后将打开你的邮件客户端并生成准备好的邮件。**请手动将文件附件添加至邮件中**（以及同文件夹下的 `battle_log.csv`）：程序无法替你完成附件添加。没有邮件客户端？请使用«关于»章节中的地址给作者写信。
- :x: **«清空»** — 清除窗口中的日志行，但在此之前会询问«清空日志？»。这是安全的：完整的日志机器人会自动保存在 `bot_data/logs` 文件夹中，会话数据也不会被重置。

你可以用鼠标选择日志中的文本，使用 Ctrl+C 或右键菜单（«复制»）进行复制。无法编辑日志 — 它仅供读取。如果你向上滚动日志进行阅读，有新日志行时它不会“跳”回底部；滚动回最底部 — 它就会重新随机器人更新而自动滚动。

> [!note] 窗口最多保留最新的 50,000 行，但仅显示最新的 4,000 行 — 否则长时间刷地牢会导致卡顿。其他所有内容都保存在 `bot_data/logs/bot_log_...txt` 文件中：机器人会自动维护该文件，通常无需手动保存日志。

日志为空时，原位置显示«日志还是空的»。连接手机后行会陆续出现。空药丸会显示«这里还没有内容»和«还没有这类记录» — 对于«错误»类别来说，这是个好消息。

> [!done] 现在你可以像看仪表盘一样阅读主页了：明白了各个区块以及日志标签颜色的含义。接下来 — 迷你栏，即游戏下方的小面板。[下一章节 →](#5)

## 游戏下方的迷你栏

当机器人运行时，你通常不需要程序的主窗口。因此，它会自动最小化到任务栏，而在游戏画面下方会显现出一个窄栏——**迷你栏**。这就像汽车的仪表盘：一览无余地展示着机器人是否在运行、当前在做什么、已经通关了多少，以及是否在呼唤你。

![刷图期间游戏窗口下方的迷你栏](images/mini_bar.png)

### 什么时候出现以及摆放位置

- :monitor: **自动出现。** 机器人启动后（“开始刷”），程序窗口随之最小化，迷你栏紧贴在游戏下方。如果你展开了程序窗口，并想在机器人运行时重新隐藏它，只需在主界面点击“最小化到迷你栏”。
- :smartphone: **紧贴在游戏正下方**，宽度与游戏画面完全一致。当你移动游戏窗口时，迷你栏会跟着移动（程序每秒检查两次）。
- :eye: **不会遮挡游戏哪怕一个像素。** 这很重要：机器人是通过截屏来“观察”屏幕的。如果面板叠在游戏上，机器人就会看到面板而不是按钮。
- :maximize-2: **底部没有空间时**（游戏窗口贴近屏幕底边），面板会置于窗口标题栏上方。如果上方也没有空间，则不会显示面板，而程序窗口会留在任务栏上。当你最小化游戏窗口时，面板会隐藏，并随游戏一同恢复。

> [!tip] 看不到迷你栏但机器人正在运行？请把游戏窗口向上挪一点：窗口下方需要大约 100 像素的空余空间。移动窗口是可以的，但不能改变其大小（我们在第 3 节讨论过这一点）。

### 面板上的内容：从左到右五列

- :activity: **状态。** 文字和一个在正常运行时会“呼吸”的彩色圆点：“启动中”、“刷图中”、“已暂停”、“调试暂停”或红色的“SOS”。下方显示**机器人当前正在做什么**以及持续秒数：例如，“战斗 · 火 · 12 秒”。接着是“房间：12 · 楼层：2”和本次运行的时间，例如“时间 00:42:17”。
- :target: **目标。** 目标名称、已完成量、需要量以及进度条。下方显示“每个房间约 28 秒”（平均时间；在第一个房间之前显示“房间用时 — 第一个房间后显示”）以及预测“距目标 ≈ 1 小时 10 分钟”。预测是机器人根据**本次**运行的速度计算的，因此刚开始会有所波动，随后便会趋于稳定。如果没有目标（“不限”），则没有进度条，预测处显示“每小时 ≈ N 泰坦石”。
- :heart-pulse: **队伍健康度。** 上一场战斗中出战泰坦的方块及其战斗后的生命值（HP）——顺序与它们在游戏屏幕上的排列一致。在第一场战斗之前显示“还没有战斗”。数字颜色会给出提示：红色——HP 低于恐慌门槛（整体或个人），黄色——低于机器人治疗泰坦的门槛，正常颜色——一切正常。破折号“—”表示在结果窗口中未能找到该泰坦的图标。
- :list: **事件。** 最近四条记录，最新的在最上方且字号较大。左侧为彩色标签，右侧为时间。
- :gamepad-2: **按钮。** 呈 2×2 排列的四个按钮。

### 机器人“当前正在做什么”

在第一列中，机器人会自动标明自己所处的阶段。这些词语的意思如下：

- **“走廊”**、**“选择门”**、**“布置队伍”**、**“战斗”**、**“结果窗口”**——单个房间的常规循环。在“布置队伍”、“战斗”、“结果窗口”和“撤回战斗”阶段后会附加房间的元素属性：“战斗 · 水 · 12 秒”。
- **“存档点”**——楼层已通关，机器人正在领取奖励。
- **“撤回战斗”**——战斗表现不佳，机器人撤退并准备重打。
- **“正在查看屏幕”**——启动后，机器人观察周围并决定从哪里开始（即“智能启动”）。
- **“在走廊暂停”**、**“等待你的决定”**、**“你在自己玩”**——机器人停止运行，原因是你按下了暂停、机器人向你询问，或是你选择了“手动通关”。
- **“等待游戏窗口”**与**“等待网络”**——机器人在等待：要么游戏未处于前台（见下文），要么与游戏服务器断开连接。

如果同一个提示保持的时间比平时长——右侧的秒数递增会提示你机器人实际上停了下来。

### 事件：标签及其含义

左侧的标签显示事件的类型：

- **元素名称**（“水”、“大地”、“火”、“混合”）——房间已通关。形如“房间 45 已通关 · 28 秒 · 最低 HP：阿拉吉 36%”的行显示房间用时以及生命值最低的是谁。
- **“楼层”**——楼层已通关（“楼层已通关，共 3 层”）。
- **“撤退”**——战斗重打。**“SOS”**——用通俗语言说明的呼叫原因。
- **“已暂停”**——“暂停：机器人打完这场战斗后等待”，然后是“机器人在走廊等待”。
- **“机器人”**——“机器人已启动”、“已取消暂停，机器人继续”、“10 分钟无应答 — 机器人自行决定”。
- **“限制”**——运行已达到目标，机器人打到存档点。
- **“注意”**——“游戏窗口未激活 — 机器人在等待。请点击游戏”。
- **“错误”**——机器人记录的错误文本原文。

长文本会被省略号截断。完整文本始终可以在主页的日志中查看。

### 按钮

将鼠标悬停在上面会显示提示文字。所有按钮的功能均与其在主界面和页眉中的“大号”按钮相同。

- :pause: **暂停 / 继续** — “软暂停：机器人打完这场战斗后等待 (F9)”。在暂停状态下，图标会变成绿色三角形，再次点击该按钮可取消暂停。在机器人刚启动时，该按钮不可用。
- :square-filled: **停止** — “紧急停止：机器人立即停止，不会向 Telegram 发送总结 (F10)”。
- :moon: **手机屏幕** — “关闭手机屏幕”，此时游戏继续运行。
- :maximize-2: **最大化** — “展开程序窗口”。迷你栏将会消失。点击任务栏上的程序窗口按钮效果相同。如果你想恢复面板，请点击主页上的“最小化到迷你栏”按钮。

> [!note] 当机器人呼唤你时，迷你栏会变红，而“需要干预”窗口会自动出现在游戏画面的中央——无需展开程序窗口。此时第一个按钮不会暂停也不会“继续”：如果 SOS 窗口被其他窗口遮挡，它会显示 SOS 窗口（提示文字——“显示 SOS 窗口：机器人在等你的决定”）。在窗口中做出回应后，迷你栏恢复正常。如何在 SOS 窗口中回应将在后续章节中详细介绍。

### 核心规则：仅当游戏处于前台时机器人才能工作

机器人会截取屏幕并在上面寻找按钮。如果游戏上方覆盖了其他浏览器、通讯软件或文件资源管理器，截图里就会是它们而不是游戏：机器人可能会“按错地方”。因此，只要另一个窗口变为活动窗口，它就会停止并等待。日志中会出现一行“[ВНИМАНИЕ] Окно игры перекрыто … Бот ждет фокуса…”，迷你栏中显示“注意”标签和“等待游戏窗口”阶段。点击游戏后——“[ИНФО] Окно снова активно. Продолжаем работу.”。

- :monitor: **点击机器人的迷你栏不会使其停止。** 迷你栏经特别设计，不会成为活动窗口：当你按面板上的按钮时，游戏仍然保持为“主窗口”。
- :triangle-alert: **“最大化”会使机器人暂时停止。** 程序窗口变为了活动窗口，而游戏窗口则没有，机器人会在最近的一步暂停。完成后点击游戏窗口，机器人就会继续运行。看守程序不会将这种等待时间视为“卡死”。
- :gamepad-2: 想要在机器人刷图的同时在电脑上工作？在游戏**旁边**打开其他窗口，而不是覆盖在游戏上方，且不要点击它们。或者将事情推迟到暂停（F9）时处理。

> [!warning] 快捷键 F9 和 F10 仅在游戏窗口或程序窗口处于活动状态时有效。在浏览器中按 F10 机器人不会停止：当你忙于其他事情时，快捷键不会响应。详情请参阅关于暂停和停止的章节。

> [!done] 现在你可以像看仪表盘一样阅读迷你栏，并明白为什么不能把游戏藏在其他窗口下了。接下来是暂停、停止和快捷键。[下一节 →](#6)

## 暂停、停止与快捷键

机器人会自动探索地牢，但有时需要让它慢下来：你想手动游玩、离开办点事或者直接结束。为此有**四种方法**，区别在于机器人停止的**平滑程度**。想象一下开汽车：“暂停”就像靠边停车并熄火，而“紧急停止”就像在行驶中拔掉车钥匙。两者都能起作用，但机制截然不同。

### 软暂停：“暂停 F9”

这是最安全平稳的方式。点击主页或迷你栏上的“暂停”按钮，或者按下 **F9** 键。

1. **点击“暂停”或按下 F9。** 日志中会出现记录 `[GUI] Сигнал 'Мягкая пауза' отправлен. Бот остановится перед следующей дверью.`（[GUI] 已发送“软暂停”信号。机器人将在下一扇门前停止。）
2. **等待机器人打完当前房间。** 它不会放弃正在进行的战斗：会打完战斗、关闭结果窗口并记录该房间的结算数据。
3. **机器人在走廊停下。** 日志中显示：`[МЯГКАЯ ПАУЗА] Бот ждет в коридоре...`（[软暂停] 机器人在走廊等待...）。主页上的状态为“已暂停”，迷你栏上显示“已暂停”，按钮变成绿色的“继续”。
4. **办完你的事情后点击“继续”（或再次按下 F9）。** 机器人写入 `[ИНФО] Пауза снята. Кэш составов и здоровья очищен. Включаю механизм Умного Старта.`（[信息] 已取消暂停。阵容和生命值缓存已清空。启用智能启动机制。）并继续进行。

> [!note] “清空缓存”意味着机器人**忘记**了先前设置的阵容以及泰坦剩余的生命值：因为在你对游戏进行操作时，一切都可能发生变化。在下一场战斗前，它会重新查看队伍选择界面并从中读取生命值。“智能启动”是指机器人先看一眼当前屏幕内容，然后才决定下一步操作（例如关闭遗留的结果窗口）。

- :eye: **在暂停状态下，你可以查看手机并在程序窗口中修改设置。** 但机器人只会在下一次点击“开始刷”时采用新设置（详情请参见主页章节）。
- :door-open: **如果在游戏中点击了内容 — 请将其切回地牢走廊**（能看到门旁旗帜的地方），然后再点击“继续”。这样机器人才能准确识别自己所在的位置。
- :gauge: **暂停期间计时不会停止。** 如果会话目标设为时间（如“120 分钟”），暂停会消耗这部分时间。不过，“看门狗”（监控机器人是否卡死的机制）不会将暂停时间计入在内，也不会触发报警。

> [!tip] 想离开一整晚或很长时间？不需要使用软暂停：只需在主页上设置好目标（泰坦石、房间数、楼层数或时间），机器人就会自动通关到存档点，停止运行并向你发送总结。

### 机器人何时会自动设置暂停

有时机器人需要协助，会自动进入软暂停状态。此时按钮同样显示为“继续”，而日志中会写入 `[ВНИМАНИЕ] Бот на мягкой паузе: ...`（[注意] 机器人处于软暂停状态：...）及具体原因。通常发生在以下情况：

- 机器人连续三次在 5 分钟内未能通关任何房间（看门狗判定其卡死）；
- 战斗撤回失败（未能识别屏幕画面，未能点击按钮）；
- 经过长时间等待后战斗仍未能开始；
- 你没有回应“没有合适的阵容”窗口，且没有可用的备用阵容。

遇到这些情况时，请先**查看手机屏幕**，排除异常（关闭多余窗口、返回走廊），然后才点击“继续”。如果设置了 Telegram，机器人还会发送带有截图的消息。

### 紧急停止：“停止 F10”

红色的“停止”按钮（或 **F10** 键）会**立即**停止机器人：程序强行结束机器人的进程。日志中记录 `[GUI] ЭКСТРЕННЫЙ СТОП. Процесс убит.`（[GUI] 紧急停止。进程已终止。），在总结卡片上原因显示为“被“停止”按钮停止”。

> [!warning] 使用 F10 会丢失的内容：机器人来不及在日志中写入 `[ИТОГ]`（总结）模块，并且**不会向 Telegram 发送会话总结**。如果当时处于战斗中，游戏中的战斗将继续进行（或留在屏幕上）— 你可以在手机上看到。在统计数据中，已经通关的房间仍会保留：机器人在每个房间通关后会立即保存记录。

何时需要使用该按钮：机器人行为异常（误触、对“暂停”无反应）或者需要立即中止一切。其他情况下，最好使用暂停或 Ctrl+Q。

### 快捷键：作用范围与功能

- :pause: **F9** — 暂停 / “继续”（功能与主页上的“暂停”按钮相同）。
- :square-filled: **F10** — “停止”。
- :gamepad-2: **Ctrl+Q** — **生成总结并停止**：机器人打完已开始的房间，停在走廊，停止运行并发送会话总结。日志中显示：`[ИНФО] Команда 'Ctrl+Q' принята! Бот завершит бой и остановится.`（[信息] 已接收 'Ctrl+Q' 命令！机器人将完成战斗并停止。），停止原因为“用户手动停止 (Ctrl+Q)”。
- :triangle-alert: **Ctrl+Shift+Q** — **立即停止 credit 但附带总结**：机器人打印 `[ЭКСТРЕННАЯ ОСТАНОВКА]`（紧急停止），写入 `[ИТОГ]` 并尝试发送 **一次** 总结到 Telegram（不进行重试，以免耽误时间）。

快捷键有时“不起作用”的重要细节：

- **F9 和 F10 由程序窗口监听**，且仅在**游戏窗口或程序窗口处于活动状态**时才生效。如果在浏览器或通讯软件中按下 F10 — 什么也不会发生。如果游戏已最小化或被其他窗口遮挡，请使用迷你栏上的按钮：它们始终有效，因为迷你栏不会抢占游戏的活动状态。
- **Ctrl+Q 和 Ctrl+Shift+Q 由机器人本身监听**， refreshments 而非程序窗口，因此只要机器人正在运行，即使当前激活的是其他窗口，它们也依然有效。
- **这些快捷键组合也被其他程序使用。** Ctrl+Q 会关闭许多程序（如 Word、Telegram Desktop），而 Ctrl+Shift+Q 会关闭某些浏览器。在机器人运行时，切勿在其他窗口中按下它们：机器人也会“听到”并停止运行。
- **机器人会在走廊**准备进下一扇门前检查 Ctrl+Q。在软暂停状态下它保持静止且不进行任何检查，因此 Ctrl+Q 只有在点击“继续”后才会生效。但如果机器人在 SOS 窗口中等待你的回应，Ctrl+Q 会立即将其停止。
- **长按按键不会重复触发指令：** 按下一次对应一条指令。
- 在机器人未启动时按下 F9 或 F10 — 日志中会显示 `[GUI] Нажата F9, но бот не запущен.`（[GUI] 按下了 F9，但机器人未启动。）

### 窗口关闭按钮与关闭 scrcpy

- :x: **机器人运行中点击程序窗口关闭按钮。** 将弹出一项询问：“停止机器人？”。点击“停止并关闭”按钮会立即关闭程序和机器人，如果游戏窗口（scrcpy）是由本程序打开的，也会随之关闭 — 且不会发送总结到 Telegram。如果不希望这样 — 请关闭询问窗口，先以软暂停方式停止机器人。
- :smartphone: **手动关闭游戏窗口（`HeroWarsBot_Arena`）。** 程序将记录 `[GUI] Окно scrcpy закрыто — останавливаю бота (он напишет итог и пришлёт его в Telegram).`（[GUI] scrcpy 窗口已关闭 — 正在停止机器人（它将生成总结并发送至 Telegram）。）。机器人会自动完成总结并发送至 Telegram；如果 10 秒内无响应 — 程序将像按下 F10 一样强制停止它。
- :pencil: 如果在“规则大师”中有未保存的更改，点击关闭按钮会首先询问“保存更改？”。

### 该 how 选择

- **想暂停一下稍后回来** — “暂停”（F9）。准备好后再点击“继续”。
- **想结束运行并获取总结** — Ctrl+Q（机器人打完当前房间、停止并向 Telegram 发送总结）。
- **需要立即停止但仍需总结** — Ctrl+Shift+Q。
- **机器人出现异常或行为怪异** — “停止”（F10），随后查看日志排查。
- **机器人通过 SOS 窗口呼叫你且你希望结束** — 点击该窗口中的“停止机器人”按钮：机器人会自动停止并发送总结。SOS 窗口将在后续专门讲解。

### Telegram 中的会话总结

如果配置了 Telegram，无论何时停止都会收到总结，**使用“停止”按钮**及直接关闭程序窗口除外：机器人在总结中会说明是你手动停止了它（“机器人已被你停止”）、完成了目标（“刷图完成”）还是因错误崩溃，并附带用时、通关房间数、楼层数、泰坦石获取量、是否有撤退和 SOS 窗口。如果断开网络，机器人会尝试重新发送总结两次（分别在 10 秒和 30 秒后），然后关闭。如何绑定 Telegram 将在单独的章节中说明。

> [!done] 现在你已经了解了如何平滑地暂停机器人以及如何完全停止它，也知道了各个按键的功能。接下来是规则设置：如何教机器人部署所需的阵容。[下一章 →](#7)

## 规则大师：“基础与房间”

“规则大师”是左侧边栏的第二个按钮（滑块图标）。在此处你要向机器人说明三件事：**何时停止**、**什么情况算作糟糕的战斗**以及**每个房间使用什么阵容**。阵容是指由 3 到 5 名泰坦组成的队伍。页面上方分为三个选项卡：“基础与房间”、“自动战术与生命值”和“规则与拦截”。本章讲解第一个也是最核心的选项卡：没有它，机器人甚至不知道派谁上场战斗。

![“基础与房间”选项卡：上方为两个设置卡片，下方为四个阵容行](images/rules_base.png)

上方是“会话参数”（两个卡片），下方是“各房间阵容”。页面底部在每个选项卡上都有一条相同的灰色栏，带有以下按钮：“保存设置”和“恢复 / 重置”。关于它的说明在章节末尾。最需要立即记住的是：**只要未点击“保存设置”，任何修改都不会被记录** — 没有一条更改会生效给机器人。

### 卡片“目标与限制”

- :target: **“本次目标”** — 机器人应当何时结束。目标始终为四者中的**一个**：“泰坦石”、“房间”、“层数”或“时间”（时间单位为分钟）。在列表中选择类型并在输入框中填入数字。输入框仅接受纯数字。“0 — 不限”的提示表示：0 会关闭目标限制，机器人将一直运行直至你将其停止。右侧的圆形箭头（“重置目标”）可将数值设为 0。
- :gem: **泰坦石由机器人自行计算**，而不是从屏幕读取：普通房间计 6 个，若结果窗口中有“x2”标志则计 12 个。因此“120 泰坦石”大约相当于在没有“x2”的情况下打 20 个房间。在你尚未保存过设置时，机器人会默认将目标设为“120 泰坦石”。
- :layers: **机器人不会在中途放弃楼层。** 当达到“泰坦石”、“房间”或“时间”目标时，它不会立即停在原地：而是在日志中记录 `[ЛИМИТ] ... Доигрываю этаж и останавливаюсь перед точкой сохранения.`（[限制] ... 打完本楼层并在存档点前停止。），通关该楼层剩余的房间，停在存档点前且不点击“激活”。这样楼层就不会半途而废，机器人将在下一次启动时首先领取奖励并结算该楼层。如果在 6 个房间内未找到存档点（每层通常有 5 个），机器人将就地停止。“层数”目标则会在通关存档点后立即触发。
- :gauge: **暂停期间计时不会停止。** “时间 — 120”的目标意味着从按下“开始刷”按钮起算 120 分钟，包含所有暂停时间。
- :calendar: **“每日重置时间（本地时间）”** — 指你所在时区的游戏新一日开始的时间。默认为 05:00。它决定了统计数据中战斗归属于哪一天，同时也影响机器人对泰坦生命值的记忆：记忆仅在同一个游戏日内有效，在新的一天机器人会从零开始。请设置为你认为新一天开始的小时数（例如你入睡的时间）。
- :send: **“设置 Telegram”** — 打开一个单独的窗口，用于开启与即时通讯软件的连接。按钮旁有一个圆点和提示文案：绿色的“SOS 通知已开启”或灰色的“Telegram 未设置”。具体连接方法将在 Telegram 章节中讲解。这里有一点很重要：该窗口中的“应用”按钮仅修改当前页面。要将设置写入配置文件，还需点击“保存设置”。

> [!tip] 该选择什么目标？当你有固定的空闲时间段时，“时间”非常方便（如“趁我做晚饭，让机器人跑一个小时”）。当需要获取指定数量的奖励时，选择“泰坦石”。当想精准通关一定数量时，选择“房间”或“层数”。如果不确定 — 请保留“泰坦石”和 120：这是一个简短的测试运行。

### 卡片“安全与模式”

这里决定了**什么情况被定义为糟糕的战斗**。机器人从结果窗口读取泰坦的生命值，并将两个数值与你设置的值进行对比。

- :heart-pulse: **“生命值恐慌阈值，%”** — 战后生命值低于多少百分比即被判定为糟糕的战斗。默认为 40。
- :swords: **“生命值损失差值，%”** — 单名泰坦在单场战斗中允许损失的最大生命值百分比。默认为 30。

两个输入框均仅接受 0 到 100 之间的整数；如果输入其他内容，框体变红并显示提示“请输入 0 到 100 的数字”，且在修正前无法保存设置。

阈值为 40 且差值为 30 的实际示例：

- 阿拉吉带着 100% 进入战斗，出来时为 80% — **一切正常**：损失了 20%，高于 40%。
- 阿拉吉带着 100% 进入战斗，出来时为 55% — **糟糕的战斗**。55% 虽然高于阈值，但损失了 45%，超出了允许的 30%。
- 阿拉吉带着 50% 进入战斗，出来时为 35% — **糟糕的战斗**。虽然只损失了 15%，但 35% 低于恐慌阈值。
- 任何泰坦阵亡或在结果窗口中未能找到该泰坦 — 无论你如何设置，始终判定为**糟糕的战斗**。

损失是基于泰坦**进入**战斗时的生命值来计算的，而不是基于 100%。因此，受伤的泰坦会比健康的泰坦更快触及阈值。阈值设得越高、差值设得越小，机器人的判断就越严格，呼叫你的频率也越高；阈值设为 0 会关闭“低于阈值”的检查（阵亡除外），差值设为 100 会关闭损失量的检查。

> [!note] 阈值和差值是针对所有泰坦全局生效的。你可以为特定泰坦设置独立的阈值，还可以开启规则“如果三人损失过大 — 算作糟糕战斗”。这些可以在相邻的“自动战术与生命值”选项卡中设置。

下方有两个开关：

- :shield-check: **“机器人自行决定”**（“回滚糟糕的战斗并挑选阵容”）— 默认**关闭**。关闭时：遇到糟糕战斗 → 弹出“需要干预”窗口，机器人等待你处理。开启时：机器人会毫不犹豫地回滚战斗并使用备用阵容重打，同时还会根据泰坦的生命值自动挑选阵容。详细说明参见机器人自主运行章节。建议在你已观察过机器人运行且信任备用阵容后再开启。
- :swords: **“手动控制安格斯大招”**（“全局，所有房间”）— 默认**关闭**，此时所有战斗（包括有安格斯的战斗）均使用自动战斗。开启后 — 对于包含安格斯的阵容，机器人在点击“战斗”后会短暂开启自动战斗数秒以释放安格斯的大招，随后再次关闭。此类战斗机器人不会自行回滚，而是会呼叫你。启动时日志中会显示所选设置：`[ТАКТИКА] Ангус: ...`（[战术] 安格斯：...）。

### 各房间阵容

在“先用主阵容，战斗不利时按顺序用备用阵容”提示下方有四行 — 对应各个房间：“大地”、“水”、“火”和“混合”。每一行 shared 都是一个独立的卡片。

- :users: **主阵容** — 房间名称下方的泰坦头像框。如果无特殊指令（例如触发了“规则与拦截”选项卡中的规则），机器人将默认使用该阵容。泰坦按从左至右排列，**顺序与他们在游戏画面中的站位一致**。若未设置阵容 — 头像框处将显示“未设置阵容”。
- :pencil: **铅笔图标（“修改阵容”）** — 打开“组建阵容”窗口。
- :list: **“备用阵容”** 及数量“N 个” — 下拉列表（展开/折叠箭头）。当战斗不利且由机器人自行决定（开启“机器人自行决定”或你未及时回应弹窗）时，机器人会按顺序尝试备用阵容。每个房间最多可添加 5 个备用阵容。展开后每个备用阵容显示为 `#1`、`#2` 等行，右侧带有叉号（“删除阵容”）。点击“添加阵容”按钮可打开同一个“组建阵容”窗口。
- :plus: **“条件”** — “+ 条件”：快速为该房间创建规则的快捷入口，例如“如果对手包含安格斯 — 使用此阵容”。点击后将打开已自动选中该房间的“新规则”窗口。具体的填写方法将在规则相关章节中讲解。

在**首次开始刷图前**请为所有四个房间指定主阵容：机器人预先并不知道你的泰坦阵容，初始状态下也没有任何预设阵容。

如何组建阵容：

1. **点击对应房间的铅笔图标**。将打开“组建阵容”窗口。
2. **点击你想上场的泰坦**。再次点击可取消选择。上方显示计数：“已选：3 / 5”以及提示“可以应用”（选中两个时显示“至少 3 个 · 还需 1 个”）。
3. **注意房间的元素属性。** 在“大地”、“水”和“火”房间中只能选择对应元素的泰坦，而在“混合”房间中可以选择所有泰坦，包括墨提斯（她是艾拉瑞特系，不能进入其他房间：“墨提斯 — 仅限混合房间”）。当选满 5 名泰坦后，其余泰坦将处于不可选状态。
4. **点击“应用”**（如果改变主意可点击“取消”；“清空”可一次性取消所有选中的泰坦）。

![“水”房间的“组建阵容”窗口：已选择三名泰坦，下方有“应用”](images/rules_picker.png)

> [!warning] “组建阵容”窗口中的“应用”仅会修改页面显示：阵容此时**尚未写入**配置文件中。只有当你点击“保存设置”时才会正式写入。每个房间的主阵容保存在 `bot_data/rules/<стихия>.yml` 文件中，备用阵容及所有数值保存在 `profile.yml` 中。无需手动修改这些文件。

如果列表中已存在相同的备用阵容（无论泰坦顺序如何），则无法重复添加：系统会弹出提示“该备用阵容已存在”。

> [!tip] 备用阵容该 how 设置？请给机器人提供更多选择：让备用阵容与主阵容至少有两名泰坦不同。如果你的阿拉吉经常在战斗后负伤，可以在备用阵容中安排防御或生存能力更强的泰坦。

### 保存与“恢复 / 重置”

底部工具栏显示当前状态：“所有更改已保存”（绿色对勾）或“有未保存的更改”（黄色图标）。当机器人运行时，旁侧会注明“机器人下次启动时使用新设置”。

- :save: **“保存设置”** 会写入你修改的内容并显示提示“设置已保存”。在点击该按钮前，机器人不会得知你的任何修改。日志中将显示 `[GUI] Профиль настроек сохранен!`（[GUI] 设置配置文件已保存！）。
- :rotate-ccw: **“恢复 / 重置”** — 红色按钮；点击后会先询问“恢复设置？”。设置将还原为**最近一次保存的状态**（备份文件 `bot_data/profile.yml.bak`）。若没有备份文件，`profile.yml` 将被删除，机器人将使用默认值。未保存的修改将会丢失。该按钮不会影响 `bot_data/rules` 文件夹中的主阵容和规则文件，但页面表单会从磁盘重新读取它们。
- :triangle-alert: ** birthplace 如果在有未保存修改的情况下离开页面**（切换到其他章节或点击窗口关闭按钮），会弹出“保存更改？”提示框，附带按钮：“保存”、“不保存”和“取消”。

机器人**仅在按下“开始刷”时读取一次设置**。虽然可以在运行过程中对其进行修改，但修改只有在停止并重新启动后才会生效。即便使用“暂停”和“继续”也不会更新它们。主页上的“启动配置”卡片精准展示了机器人当前正在运行所依据的设置。

> [!warning] 如果 `profile.yml` 文件已损坏，主页日志顶部将出现 `[ОШИБКА] Файл profile.yml поврежден!`（[错误] profile.yml 文件损坏！），页面上将显示默认值，且点击“保存设置”时会拒绝写入（显示“profile.yml 已损坏——设置未保存”）。此时请点击“恢复 / 重置”。

## 规则大师：「自动战术与生命值」

「规则大师」的第二个标签页。在第一个标签页（「基础与房间」）中，你设置了阵容和通用阈值。在这里，你要告诉机器人**当出现异常时该如何应对**：首先进入哪扇门、什么情况算作糟糕战斗、尝试其他阵容多少次、等你多久以及如何治疗受伤的泰坦。所有字段已填入合理的数值，因此即使你不做更改，机器人也能正常工作。当发现它的行为不符合你的预期时再修改即可。

![「自动战术与生命值」标签页：顶部条幅、四扇门、并排的两个卡片以及底部的个人阈值](images/tactics_tab.png)

与第一个标签页一样，**在你点击「保存设置」之前不会写入任何内容**，而机器人只在你点击「开始刷」时读取一次设置。如果在刷资源期间修改了设置，将在停止并重新启动后生效。

### 顶部蓝色条幅

其中简要说明了机器人在遇到糟糕战斗时的操作：回滚战斗并使用备用阵容重试，而成功的阵容会被记录为规则。

如果第一个标签页中的「机器人自行决定」开关已关闭，条幅中会增加一句话。这句话很重要，因此我们单独说明。**如果没有勾选「机器人自行决定」，有两项功能将无法工作：备用阵容和治疗阵容。** 该标签页上的其他所有功能都会始终工作：

- :door-open: 门的顺序；
- :gauge: 等待你响应 SOS 窗口（当战斗处于糟糕状态时，机器人用于呼叫你的窗口）；
- :triangle-alert: 糟糕战斗的标准；
- :heart-pulse: 个人恐慌阈值。

### 「门的优先级」

在走廊里，机器人经常会同时看到几扇门：对应各个元素（水、大地、火）各一扇，或者「混合」门。房间里有敌人等待着你，每个元素都有自己的阵容。顺序决定了**机器人将首先打开哪扇门**。默认顺序为：「水」、「混合」、「大地」、「火」。

四个位置从左到右排列，中间有箭头；每个位置都有 1 到 4 的编号。点击某个位置并选择一个元素。不会出现重复：如果选择了已存在于其他位置的元素，它们只需**互换位置**。原本是“水、混合、大地、火”，如果在第一位选择了“火”，就会变成“火、混合、大地、水”。

两点注意事项，以免在游戏中感到困惑：

- 如果某扇门**被「Skip」规则禁止**（详见「规则与拦截」章节），机器人即使把它排在第一位也会跳过它。如果所有门都被禁止，它将选择顺序中的第一扇门。
- 如果开启了「机器人自行决定」，机器人有时会**自行选择另一扇门**，而不是按顺序选择：去往可以为受伤泰坦提供治疗的地方，或者绕过对伤员有危险的门。此类选择会在日志中显示为 `[НАВИГАЦИЯ] Выбрана комната ... по здоровью титанов: ...`。

### Карточка «Критерии плохого боя и SOS»

- :swords: **«每个房间尝试的备用阵容数»**——在同一个房间中，机器人自行回滚战斗并换用另一个阵容重试的次数。取值 1 到 3，默认为 2。如果用完尝试次数后战斗依然糟糕，机器人会向你呼救。仅在「机器人自行决定」启用时有效。不能超过 3 次：将同一场战斗重试 10 次没有意义，而且每次尝试都需要消耗时间。
- :gauge: **«SOS 窗口无人应答的超时（分钟）»**——机器人在自行决定之前，等待你响应「需要干预」窗口的分钟数。取值 0 到 60，默认为 10。字段下方的提示说明为「0 表示一直等待」：**0 意味着“一直等待”**，机器人会站着一直等你，甚至等到早晨。这在**未**启用「机器人自行决定」时也有效。关于机器人自行决定的具体操作（回滚战斗、接受战斗或暂停），请参阅 SOS 窗口章节。
- :users: **«满足以下条件时视为糟糕战斗»**——阵容的总损失：「泰坦 ≥ 3」且「失去 ≥ 40」「% 生命值（每个）」。这种检查可以捕获**单个人都能撑住**，但整体阵容却崩溃的情况。如果三个泰坦各自失去了 40% 或更多的生命值，即使没有一个降至恐慌阈值以下，这场战斗仍被视为糟糕。提示「0 个泰坦表示不检查」意味着：在第一个字段中输入 0，检查就会关闭。第一个字段取值 0 到 5，第二个字段取值 0 到 100。

实际示例。阵容：阿拉吉、海伯利昂、瑞格尔、伊亚里、卢米拉。战斗结束后，阿拉吉失去了 45%，瑞格尔失去了 42%，伊亚里 regained/lost 40%，其余失去 10%。有三个人失去了“40% 或更多”——战斗将被判定为糟糕，即使每个人的剩余生命值都高于恐慌阈值。如果伊亚里只失去了 35%，就只有两个人满足条件，整体检查就不会触发。

> [!note] 糟糕战斗的其他特征——恐慌阈值和允许损失额度——位于第一个标签页「基础与房间」中。只要触发了**至少一个**特征，战斗就被视为糟糕：有人阵亡或在窗口中未找到、有人生命值低于阈值、有人损失超过允许额度，或者触发了总损失检查。

如果你输错了数字（字母或超出范围的数字），该字段会变红，下方会出现“数值介于 ... 到 ... 之间”，在修正之前将无法保存设置。

### Карточка «Авто-сборка пака отхила в Смешанной»

经常会出现这种情况：一个泰坦连续几场战斗挨打，只剩下一半生命值走来走去。迟早他会跌到阈值以下，战斗就会变成糟糕战斗。“治疗”是指机器人**自动组建一个特殊阵容**来为伤员疗伤（在阵容中加入治疗者，以此提升伤员的生命值）。机器人仅针对「混合」房间组建此类阵容，因为在那里可以任意放入任何泰坦。

这仅在启用「机器人自行决定」时有效，且仅在你自己设置的治疗规则未触发时生效（自定义规则的优先级更高）。

- :heart-pulse: **«生命值低于此值时治疗泰坦（%）»**——默认为 60。生命值高于此数值的泰坦被视为健康。**0 会完全关闭**治疗阵容。但存在一个下限：如果泰坦的生命值已经**低于恐慌阈值**，在「混合」房间中是无法进行治疗的，机器人不会触碰他。
- :users: **«为伤员从阵容中移除谁»**——带箭头的三个位置。当需要加入伤员而阵容位置满了时，将移除某个人。点击某个位置并选择泰坦：列表按元素分栏显示。**«— 自动 —»**（默认设置）意味着：机器人会从阵容末尾移除泰坦，但**不会动治疗者**。对于阵容“海伯利昂、瑞格尔、伊亚里、卢米拉、阿蒙”，依次为阿蒙，然后是卢米拉。如果选择了已位于其他位置的泰坦，它们将互换位置。

简而言之，机器人是如何进行治疗的：

1. 检查谁的生命值低于 60% 但高于恐慌阈值，且其中哪些没有被「Skip」规则所禁止。
2. 每次**只治疗一个**，从最接近自己阈值的那个开始。首先治疗主力（来自基础阵容），然后是备用。
3. 如果阵容中没有伤员，他将取代被移除的泰坦。但是，对于本就在“自己”的房间中接受治疗的泰坦（水系和大地系：其基础阵容中有治疗者），机器人不会将他们拉入「混合」房间，除非他们在那里连续两场战斗都没有升至阈值以上。火系泰坦在“自己”的房间里无法治疗，因此对其立即启用治疗阵容。
4. 如果伤员已在阵容中，但连续两场战斗都没有起色，则由一位**健康且充满能量的治疗者**（生命值 80% 以上，能量 60% 以上）取代被移除的泰坦。
5. 如果阵容中没有治疗者、会输给这些敌人、对伤员危险或需要手动战斗（安格斯），则不会选择该阵容。

为什么机器人如此谨慎？它不会去治疗你未曾指定的泰坦：对于不在你的阵容和规则中的泰坦，机器人不会自行放入。如果未能组建阵容（泰坦未能填入槽位），机器人不会停止，而是放入普通阵容，并且**在本次运行结束前不再治疗该泰坦**。

在日志中，这可以通过 `[ТАКТИКА] Пак отхила (бот собрал сам): ...` 和 `[ТАКТИКА] Отхил: ...` 这几行看出（解释了为什么不治疗伤员）。

### Карточка «Личные пороги паники титанов, % ХП»

通用恐慌阈值（默认为 40）适用于所有人。但有些泰坦你不想过早失去，而有些泰坦即使生命值较低也能轻松承受。你可以为他们设置**专属阈值**。

- 底部提示「其他泰坦——通用阈值 40%」（数字来自第一个标签页）。当没有个人阈值时，显示为「没有个人阈值——所有泰坦使用通用阈值。」。
- 点击「为泰坦设置个人阈值」。将打开一个小窗口「个人恐慌阈值」：从列表中选择泰坦并输入 0 到 100 之间的数字。点击「应用」。窗口会提示「通用阈值——40%」，方便你进行对比。列表中仅显示尚未设置个人阈值的泰坦。
- 每个已设置的阈值都是带泰坦名称和黄色数字的标签。点击标签可修改阈值（无法更换泰坦，必须先删除再重新添加）。标签上的**叉号**会删除阈值，泰坦将重新使用通用阈值。

如果战斗后该泰坦的生命值**低于其个人阈值**，则视为糟糕战斗。例如：通用阈值为 40，而瑞格尔设置为 60。瑞格尔离开战斗时剩 55% 生命值——战斗被判定为糟糕，尽管对其他人来说 55% 是正常的。

> [!tip] 从哪里开始？在看到几十个房间之前，不要修改任何内容。如果发现机器人因为同一个泰坦频繁呼叫你，可以为他设置一个较低的个人阈值。如果机器人为了治疗频繁更换阵容，请**调低**「生命值低于此值时治疗泰坦（%）」中的数值。如果完全不想让他治疗，请输入 0。

> [!warning] 如果你将「SOS 窗口无人应答的超时（分钟）」设置为 0 然后去睡觉，而机器人弹出了呼叫窗口，它会一直等到早上。最好保留 10–15 分钟并配置好 Telegram：这样你能立即得知问题，如果来不及处理，机器人也会自行决定。

> [!done] 现在你知道了如何设置门的顺序、什么情况算作糟糕战斗以及机器人如何治疗伤员。接下来是 Telegram 以及呼叫你寻求帮助的窗口。[下一章 →](#9)

## 规则大师：「规则与拦截」

「规则大师」的第三个标签页。在第一个标签页中，你设置了每个房间的**主力阵容**，在第二个标签页中设置了机器人遇到危险时的应对方式。在这里，你将教会它**例外情况**：“通常使用主力阵容，但如果发生了这种情况——就采取其他做法”。每一个这样的例外情况都被称为**规则**。而“拦截”是指规则“拦截”了主力的阵容选择，并换上自己的阵容。

规则的理解方式始终相同：**“如果 [条件] —— 那么 [动作]”**。例如：

- :heart-pulse: “如果阿拉吉生命值低于 50% —— 安排带有治疗者西格德的阵容”。
- :swords: “如果房间里有安格斯、希尔瓦和韦尔多克 —— 安排这个阵容”。
- :door-open: “如果阿拉吉生命值低于 30% —— 不要进入「火」”。
- :users: “如果房间里有安格斯、阿瓦隆和伊甸 —— 停下来询问我”。

![“规则与拦截”标签页：元素过滤器、带有图标、阵容和开关的规则列表](images/rules_intercepts.png)

每个元素的规则都是独立的：「大地」、「水」、「火」和「混合」各有单独的列表。当机器人进入「火」之门时，它只查看「火」的规则。和其他标签页一样，**在你点击「保存设置」之前，什么都不会被写入**，而机器人只会在你点击「开始刷」时读取一次规则。

> [!note] 许多规则你根本不需要手动编写。如果启用了「机器人自行决定」，机器人会**自动记住**撤退后的成功阵容，并自动添加“黄金规则”。它们会出现在同一个列表中（详见下文）。只有当你明确知道“不能这样做”或者“在这种情况下正好需要这个阵容”时，才需要编写自定义规则。

### 规则有哪些类型

规则的条件是三种之一，动作也是三种之一。组合在一起形成了常见的类型：

- :heart-pulse: **按生命值或能量救急。** 条件是“某泰坦的生命值（或能量）低于 N%”，动作用于更换其他阵容。在列表中显示为 **«治疗»**（按生命值）或 **«能量»** 图标。回血就是这样实现的：当泰坦受伤时，使用带有治疗者的阵容。
- :swords: **针对这些敌人。** 条件是“房间里有所有这些敌人”，动作用于使用自定义阵容。图标为 **«敌人»**。可以从机器人在地下城中识别的 13 个敌人中进行选择。
- :door-open: **«Skip» —— 禁止。** 条件是“泰坦的生命值或能量低于 N%”，动作用于不使用该泰坦且不进入该房间。图标为 **«跳过»**，右侧带有 «跳过房间» 标记。
- :users: **«询问你».** 任意条件，动作是不自行决定，而是呼叫你。右侧带有 **«询问你»** 标记，图标取决于条件（«生命值»、«能量»、«敌人»）。当它触发时，机器人将打开 «没有合适的阵容» 窗口并等待你的回复。如果你未在“自动战术”中设定的时间内回复，它将自行决定。

图标为 «生命值»（而非 «治疗»）意味着条件是按生命值，而动作是 «询问你»。如果完全没有条件，则没有图标，名称下方会写着 «没有条件——规则永远不会触发»。

现在介绍 «Skip»，因为它同时承担两项工作。示例：在 «火» 中有一条规则“阿拉吉，生命值低于 30%”。

1. **门。** 只要阿拉吉的生命值低于 30%，机器人就不会进入 «火»，而是选择另一扇门。如果所有门都被禁止，机器人将按顺序选择第一扇门。
2. **“黑名单”。** 在该房间中不会出战阿拉吉：包含他的任何阵容，机器人都会丢弃并选用下一个。如果**主力**阵容也包含被禁止的泰坦，导致无阵容可用 —— 机器人将停止并打开 «没有合适的阵容» 窗口。

> [!warning] «Skip» 无法按敌人设置。机器人是在进入门**之后**才识别敌人的，因此无法根据敌人来选择门。在“按敌人”的规则窗口中，«Skip» 复选框不可用。如果你想绕过含有特定敌人的房间 —— 请设置 «询问你» 规则，这样决定权就在你手中。

### 机器人按什么顺序检查规则

战斗开始时，机器人会**按以下顺序**遍历房间规则：

1. **«Skip»** —— 首先，机器人会整理泰坦的“黑名单”：即被已触发的 «Skip» 规则所禁止的泰坦。包含此类泰坦的阵容将不会被使用，即使规则本身要求使用它（这被称为否决权：禁止高于任何规则）。
2. **救急** —— 条件中包含泰坦生命值或能量的规则。这里也包括“针对敌人，且阿拉吉生命值 < 50%”的规则（敌人加生命值）：它们会在此处直接检查，位于普通针对敌人规则**之前**。
3. **针对敌人** —— 条件中仅包含敌人的规则。
4. **主力阵容** —— 房间的主力阵容，如果没有任何规则适用。

在每个分组内部，机器人会**从上到下**依次进行，并采用第一个触发的规则。这就是需要箭头的原因：如果两条针对敌人的规则同时满足条件，靠上的规则胜出。然而，“救急”规则始终强于“针对敌人”，无论它们在列表中的位置如何。**已关闭**的规则不参与检查。

条件会与机器人了解到的你的泰坦信息（它从阵容选择屏幕和战斗后获取生命值及能量）进行对比。如果机器人尚未看到泰坦的健康状况，则认为其满血，且“低于 N%”的规则不会触发。如果条件中包含多个泰坦（机器人自行记住的规则会出现这种情况），必须**同时**满足所有条件。针对敌人也是如此：只有当房间里包含列出的**所有**敌人时，规则才会触发。

### 规则列表：行中包含什么

顶部是 «启用的规则» 和带有规则数量的灰色标签，右侧是提示：«选择一个元素后才能调整顺序»（显示全部时）或 «列表中靠上的规则先被检查»（选择单个元素时）。下方是筛选按钮 «全部»、«大地»、«水»、«火»、«混合» 以及 «新规则» 按钮。再下方是列标题“№”、«条件»、«动作»、«开关»。

在每一行中，从左到右依次为：

- **序号** —— 在其对应元素列表中的位置。序号越小，规则越早被检查。当选择了**单个**元素时，序号旁会显示 «上移» 和 «下移» 箭头。如果选择了 «全部» 则没有箭头：元素按顺序显示，彼此之间不参与排序竞争。
- **图标** —— 房间元素和规则类型（«治疗»、«生命值»、«能量»、«敌人»、«跳过»）。
- **名称** 和下方的灰色行 —— 用文字说明的条件，例如 «阿拉吉：生命值低于 50%» 或 «房间里的敌人：安格斯，希尔瓦»。
- **动作** —— 箭头和阵容泰坦图标框（从左到右，与游戏中一致），带有 «更换阵容» 标注。或者是 «询问你» / «跳过房间» 标签。
- **«开关» 开关** —— 启用或关闭规则。
- **铅笔** «修改» 和 **叉号** «删除»。

如果没有规则，列表位置会显示：“没有规则。点击«新规则»——或者机器人在撤退后自行记住规则。”

### 开关、箭头、叉号与“清空”

- :check: **开关。** 关闭的规则会变灰，但**仍保留在列表中**，机器人只是直接跳过它。这是“临时停用规则”的最佳方式：无需重新组建阵容。启动时日志中将出现一行 `[ПРАВИЛА] Выключено правил: N, бот их пропускает.`
- :chevron-up: **«上移» 和 «下移» 箭头** 可以与邻近规则互换位置。当同一分组的两条规则可能同时适用，且哪一条先检查非常关键时，就需要用到它们。
- :x: **«删除» 叉号。** 底部将出现通知“规则«…»已删除”，并带有 **«撤销»** 按钮。只要通知显示在屏幕上，就可以将规则恢复到原位置。
- :trash-2: **«清空所有规则»** 仅删除**当前可见**的内容。如果选择了 «水» —— 将删除水的规则；如果选择了 «全部» —— 将删除所有规则。首先机器人会再次确认：“«删除所有规则？»”，并说明删除了多少条以及哪些规则（«全部删除» 按钮）。之后同样会出现通知“«已删除规则：N»”，并带有 «撤销» 按钮。

所有这些操作仅修改当前页面。修改只会在点击 «保存设置» 后写入文件，且**仅写入有所更改的元素**。如果未保存就离开页面，窗口会询问“«保存更改？»”。

> [!tip] 如果你不确定是否要删除某条规则，最好用开关将其关闭。对于机器人自行记住的规则，还有一个原因（见下文）：已关闭的规则机器人不会触碰或重新创建，而已删除的规则可能会再次出现。

### 分步了解 «新规则» 窗口

点击 «新规则»（或在第一个标签页房间卡片底部的 «条件» 按钮）。窗口将会打开。如果已选择单个元素，它会立即推荐该元素。行中的铅笔图标会打开具有标题 «修改规则» 的相同窗口。

![«新规则» 窗口：元素和名称、三个触发条件、条件字段、动作和阵容](images/rule_editor.png)

1. **在 «房间元素» 字段中选择元素。** 规则将仅在该处生效。可选择哪些泰坦取决于元素：在 «大地» 中只能选择大地泰坦，在 «水» 中只能选择水系泰坦，而在 «混合» 中可以选择任何泰坦。如果稍后更改元素 —— 窗口会自动调整选择。
2. **为规则命名（可选）。** «规则名称» 字段可以留空：此时名称将由条件自动生成，例如 «阿拉吉：生命值低于 50%»。当规则触发时，机器人会在日志中写入此名称。
3. **选择 «触发条件»** —— 机器人应该关注的内容：«按生命值»、«按能量» 或 «按敌人»。
   - «按生命值» 和 «按能量»：选择 **«泰坦»** 并要在 «生命值低于，%»（或 «能量低于，%»）字段中输入 0 到 100 之间的数字。默认生命值为 35，能量为 100。如果输入的不是数字或超出范围，该字段将变红，下方会出现 «0 到 100 之间的数字»。
   - «按敌人»：在 «房间里的危险敌人» 网格外框中勾选所有需要**同时存在**的敌人。旁边会显示 «· 已选：N»。如果不选择任何人 —— 则无法保存。
4. **选择 «触发时的动作».** 有两个互斥的复选框：“停下来询问我”和 «禁止进入房间（Skip）»。如果两个都没勾选 —— 规则将**使用阵容**。
5. **要求磨合泰坦（可选）。** 规则仅在选定的泰坦（1 到 5 个，来自任意元素）在本次运行中已经参加过战斗时才会触发。例如，阵容需要西格德，而只要他还没参加过战斗你就不想出战他。旁边的叉号可以取消磨合。磨合仅存在于使用阵容的规则中。在软暂停和手动战斗后，机器人会忘记泰坦的状态，磨合将重新开始。
6. **选择 «此规则的阵容».** 点击 «选择阵容»，并在 «组建阵容» 窗口中设置 **3 到 5 个泰坦**（与主力阵容相同）。对于“询问我”和 «Skip»،不需要阵容，该处会显示 «此动作不需要阵容»。
7. **点击 «保存规则».** 在按钮保持灰色期间，窗口底部会说明缺少什么：«请选择阵容：3 到 5 个泰坦»、«请至少选择一个敌人» 或 «请修正数字：0 到 100»。«取消» 将关闭窗口且不作任何更改。

新规则会排在对应元素的**第一位**，修改后的规则保留在原位置（如果更改了元素，则排在新元素的第一位）。与其它设置一样，它会在点击 «保存设置» 后存入文件。如果是通过第一个标签页上的 «条件» 按钮打开窗口，保存后会出现通知：“规则«…»已添加至«规则与拦截»标签页”。

> [!note] 机器人自行记住的规则可以通过铅笔图标打开并修改。窗口中未显示的任何内容（例如“伤害容容度”或多余的生命值条件）都将**按原样保存**。窗口将以灰色行显示该条件：“条件中的其他内容（将按原样保存）：…”。

### 机器人自行记住的规则

如果启用了 «机器人自行决定»، 列表中会出现非你编写的规则。可以通过名称识别它们：

- :refresh-cw: **«自动：房间里有 安格斯 + 希尔瓦»** —— 机器人撤退了失败的战斗，换用另一个阵容重试并成功通关。机器人记住：“针对这些敌人使用此阵容”。名称下方写着 «机器人在撤退后记住»（或 «撤退后你的阵容，由机器人记住»，如果你在 SOS 窗口中亲自选择了阵容）。如果阵容因某种条件失败（例如“阿拉吉低于 50%”），该条件将被添加到规则中。此类规则会排在第一位。
- :star: **«黄金：房间里有 安格斯 + 希尔瓦»** —— “«该阵容经常战胜这些敌人»”。启动时，机器人会查看历史记录，选取针对该敌人组合进行了 **5 场及以上战斗** 且胜率达到 **80% 及以上** 的阵容。主力阵容、救急规则阵容以及你的备用阵容不会成为“黄金”规则。

在文件中，这些规则名称不同（“针对...的反制阵容：…”、“针对...的黄金规则：…”），在日志中也是这样记录的：`[ОБУЧЕНИЕ] Новое правило '…': пак […]. Сохранено на 1-е место.` 窗口只是以简短人性化的方式展示它们。如果你重命名规则 —— 将会看到你自己设定的名称。

关于这些规则，了解以下内容会很有用：

- **机器人不会重复创建同类规则。** 具有相同条件的规则不会被第二次创建：旧规则的阵容会被更新并升至顶部。
- **并非每次成功的撤退都会被记住。** 如果一场糟糕的战斗仅因泰坦在进入时处于受伤状态，而在 100% 生命值时完全可以正常打通（“与敌人无关”），则不会创建规则。
- **已关闭的规则机器人不会触碰：** 不会开启也不会重写。它不会再次记住完全相同的阵容，已关闭的“黄金”规则也不会恢复。
- **已删除的规则可能会恢复。** 下次启动时，“黄金规则”会再次创建，除非针对这些敌人已存在其他规则。如果不喜欢 —— 请用开关关闭它。如果再次出现同样的撤退结果，机器人将重新创建“自动”规则。
- **当窗口打开时，机器人可能会将新规则写入文件。** 当你点击 «保存设置» 时，窗口将重新读取文件并将这些新规则排在顶部，不会丢失任何内容。如果你浏览该标签页而不进行任何更改 —— 你将看到来自磁盘的最新列表。

> [!warning] 如果元素规则文件损坏（例如手动修改且缩进错误），窗口会提示，例如对于水元素：«规则文件已损坏：bot_data/rules/water.yml——窗口不会修改该元素的规则»。其他元素将正常工作。无需手动修改文件：点击主界面上的 «把日志发给作者» 并说明发生了什么。

> [!tip] 从何入手？不要预先编写任何内容。在启用 «机器人自行决定» 的情况下玩上几十个房间，然后再来看看这里：机器人已经记住了几条规则。用开关关闭不理想的规则，用箭头将好的规则上移。当你发现重复出现的麻烦时，再添加你自己的规则：“阿拉吉总是受伤挂彩” —— 救援规则；“这组敌人总是打败我的主力阵容” —— 针对敌人的规则。

> [!done] 现在你已经学会了如何向机器人教授例外规则，并理解了它为什么选择特定阵容。接下来 —— Telegram 以及呼叫你寻求帮助的窗口。[下一章 →](#10)

## 当战斗打得不好时：SOS 窗口

机器人几乎总是能自行处理。但有时它会遇到没有人类干预就无法解决的情况：战斗虽然赢了，但付出的代价太高，或者规则没有提供任何合适的阵容。这时机器人会**停止并弹窗呼唤你**。SOS 就像船只的求救信号：“需要帮助”。在你回答之前，机器人不会点击任何东西并保持等待（但不会永远等下去，详见下文）。

一共有三个窗口，每个窗口对应不同情况：

- :triangle-alert: **«需要干预»** — 战斗已结束， boot 结果不好。这是主要窗口，出现最频繁。
- :users: **«没有合适的阵容»** — 机器人尚未开始战斗：规则没有为这个房间提供阵容。
- :check: **«阵容成功了»** — 你亲自选择了另一个阵容，且该阵容赢了，机器人询问是否记住它。

![“需要干预”窗口：原因、房间、敌人、带生命值条的你的阵容以及三个按钮](images/sos_window.png)

> [!note] 窗口何时出现：如果«机器人自行决定»被**关闭**（默认如此），窗口会在**每次**打得不好的战斗后打开。如果开启，机器人会先尝试自行解决，只有在无法处理时才会呼唤你：手动战斗（安格斯）、结果窗口无法读取、阵容是你选择的、在房间里机器人已经回退了允许的次数、或者没有备用阵容。什么是“打得不好的战斗”以及如何设置 — 详见“基础与房间”和“自动战术”章节。

### «需要干预»窗口

顶部是一句简短提示：“战斗打得不好。怎么办？”。下方是具体事实，方便你无需翻看日志即可做出决定：

- **原因。** 机器人究竟对什么不满。例如：“临界门槛！阿拉吉仅剩 12% 生命值（门槛：40%）”、“超过损失 Delta！瑞格尔损失了 45% 生命值（容许度：30%）”、“致命！伊亚里已阵亡…”、“阵容损失惨重！…” 或 “无法读取结果窗口：未找到…”。泰坦名称使用程序语言显示。
- **房间。** 门的元素和房间编号：“火 · 房间 54”。
- **敌人。** 对战的泰坦头像方块。如果未识别出敌人，则不会显示此行。
- **你的阵容。** 每个泰坦附带有生命值条和“战前生命值 → 战后生命值”文本：“36% → 12%”。如果泰坦的生命值低于其恐慌门槛（通用或个人），血条和数字会显示为**红色**。刚带伤参战且出来时几乎没血 — 一眼就能看出来。
- **计时器。** 底部显示：“如果不回答，机器人将在 9:41 后自行决定”。最后一分钟显示为黄色，随后变为“机器人正在决定…”。如果在“自动战术”中设置为 0，则不会显示此行：机器人将一直等待你。

按钮（从右到左，最右侧为主按钮）：

1. **«回退战斗»**（蓝色）。用另一个阵容重打这场战斗。窗口会隐藏，并打开带有当前阵容的«组建阵容»；更换泰坦并点击«用这个阵容回退»。后续操作详见下文“撤回战斗”部分。如果不做选择直接关闭«组建阵容»，SOS 窗口会重新出现，不会丢失任何进度。
2. **«忽略»**（灰色）。接受战斗现状：房间算作通关，机器人带着剩余的生命值继续前进。适用于你对损失感到满意的情况（例如，泰坦本就是带伤参战，总体来说没问题）。
3. **«手动通关»**（灰色）。机器人不做任何点击，你亲自在游戏中通关该房间。机器人在你返回走廊前会一直等待：门的旗帜必须连续 2 秒可见。如果最后显示的是结果窗口，则算作通关；如果你未获胜就退出了，则不计通关。关闭结果窗口而不重打，战斗将按原样计入。手动通关后，机器人会清空泰坦生命值和槽位中的阵容（它会在队伍选择界面重新读取），然后继续自动游戏。

> [!warning] 使用了**手动安格斯大招**的战斗无法回退：其结果窗口中没有“再试一次”按钮。窗口中不会显示«回退战斗»，而是会显示红色的 **«停止机器人»**，只保留«忽略»或«手动通关»。

### 撤回战斗：机器人做出选择后会做什么

窗口关闭，指令已发送给机器人。接下来它会自行处理一切，日志中会带有 `[ОТКАТ]` 标记：

1. 点击结果窗口上的 **“再试一次”** 并等待战斗加载（有时需要 20–30 秒甚至更久，因此它最多会等待一分钟）。
2. 将战斗**暂停**（一次）并点击 **“撤退”**。
3. 返回走廊，进入**同一个房间**并上阵你的新阵容。

如果战斗依然不理想 — 窗口会再次出现。如果打得很好 — 此时会弹出«阵容成功了»窗口（见下文）。

如果与游戏的连接丢失（“加载”图案卡住不消失），机器人不会放弃：它最多等待游戏 15 分钟并在日志中记录。只有在回退彻底失败时，机器人才会将截图保存到 `bot_data/debug/`，进入软暂停并向你发送 Telegram 消息。详见故障排除章节。

### «没有合适的阵容»窗口

当机器人已经选择了门并查看了敌人，但**没有可上阵的阵容**时出现。原因有两种，都源于你的规则：

- 触发了“询问我”规则（它就是为此设计的）；
- 房间的基础阵容包含被“Skip”规则禁止的泰坦（机器人会提示类似“致命：所有阵容均被淘汰…”）。

窗口会询问：“规则没有为这个房间给出阵容。怎么办？” 里面同样有“原因”、“房间”和“敌人”，但没有血条：因为战斗尚未发生。按钮包括：

- **«组建新阵容»**（蓝色）— 打开«组建阵容»，里面的按钮叫«应用»。机器人将上阵选定的泰坦，并**立即将该阵容保存为针对这些敌人的规则**（此处不会在保存前进行校验，请注意）。
- **«手动通关»** — 你亲自通关房间，机器人在走廊等待。如果获胜，房间将被计入。
- **«停止机器人»**（红色）— 机器人生成会话总结并关闭。

这里没有«忽略»按钮：因为没有发生战斗，没有什么可接受的。

### «阵容成功了»窗口

当**你亲自选择**的阵容赢得战斗时（通过«回退战斗»或«试试别的»，在窗口中或在 Telegram 中），就会出现此窗口。如果是机器人自己选择的备用阵容并取得了胜利，机器人会自动记住它，不会向你询问。

内部包含：房间、敌人（来自上一个 SOS 窗口，前提是不超过 15 分钟前）以及战斗后带生命值的你的阵容。问题是：“正在测试的阵容赢了。要把它保存为针对这些敌人的规则吗？” 按钮包括：

- **«保存阵容»**（绿色）— 机器人将使用此阵容记住“针对这些敌人”的规则。在规则列表中，它将显示为“自动：…”或«撤退后你的阵容，由机器人记住»。
- **«试试别的»** — 再次打开«组建阵容»并进行回退：机器人将用另一个阵容重打这场已获胜的战斗。

如果你不回答 — 在计时器时间到达后（提示为“如果不回答，机器人将在…后自行保存阵容”），机器人会自动保存阵容，就像你点击了«保存阵容»一样。

### 窗口关闭按钮与«停止机器人？»

窗口没有“直接关闭”选项：如果直接关闭窗口，机器人将一直等待回答。因此点击关闭叉号会询问：**«停止机器人？»**。如果你回答“停止机器人”，机器人将结束运行，生成总结并将其发送到 Telegram。如果它在 10 秒内没有响应，程序会自动停止它。在«阵容成功了»窗口中，提示有所不同：这里的停止相当于“停止 F10”，**不会将会话总结发送到 Telegram**。如果改变主意 — 点击«取消»，窗口将保持打开。

### 如果不回答会怎样

每当你未在“自动战术”设定的时间内回答（«SOS 窗口无人应答的超时（分钟）»：默认为 10，最高 60，0 表示一直等待），机器人会记录 `[ТАКТИКА] Ответа нет 10 мин. Решаю сам.`，窗口关闭，同时你会收到一条 Telegram 消息告知机器人已自行决定。即使在关闭«机器人自行决定»时此机制依然有效。具体决定取决于窗口类型：

- **«需要干预»：** 如果有备用阵容且战斗可以回退（非安格斯，且房间内的尝试次数未用尽） — **回退**并上阵备用阵容；否则如果所有泰坦都存活 — **接受**战斗（«忽略»）；否则（有人阵亡或在窗口中未找到） — **软暂停**。
- **«没有合适的阵容»：** 如果有无伤员且无禁止泰坦的合适备用阵容 — 机器人将其上阵**且不保存规则**；如果没有 — **软暂停**。
- **«阵容成功了»：** 保存该阵容。

软暂停 — 类似于“暂停 F9”按钮：机器人在走廊里等待，直到你点击«继续»。

> [!tip] 刚在机器人自行决定的一瞬间作出了回答？没关系：机器人会忽略旧的回答并记录 `[ЛОГИКА] Пропускаю ответ ...: он пришёл на прошлое окно.`。

### 通过 Telegram 进行回答

如果配置了 Telegram，**同一个问题**也会发送到聊天框中：游戏截图、说明文本（房间、敌人、原因、带生命值的阵容）以及按钮。你可以在任何方便的地方回答：在聊天框中回答 — 电脑上的窗口会自动关闭，反之亦然。

- **«回滚 (组建阵容)»**（绿色）— 机器人会要求 numerically 在聊天框中用逗号或空格隔开输入 **3–5 个泰坦**的名称，显示它识别出的泰坦，并询问“是否全部正确？”（«确认阵容» / «重新输入»）。对于手动安格斯战斗和«没有合适的阵容»，此按钮替换为红色的«停止机器人»。
- **«手动通关»** 和 **«忽略 (继续)»** — 与窗口中的功能相同。对于«没有合适的阵容»，没有“继续”选项。
- Telegram 中收到«阵容成功了»的前提是该阵容也是你从 Telegram 发送的：«确认并保存»或«回滚并重试»。

如果网络断开，消息将在稍后发送（机器人会不断重试），而电脑上的窗口会保持打开。Telegram 设置详见对应章节。

### 迷你栏与 SOS 窗口

如果程序窗口最小化到迷你栏，SOS 窗口将出现在**游戏中央**。此时迷你栏会变成红色，点击其«SOS»按钮可将置底的窗口置顶显示在游戏之上。

> [!tip] 如何选择？查看«你的阵容»。如果某个泰坦是带伤参战且血量下降，其他人正常 — 通常选择«忽略»就够了。如果是你熟悉的敌人且实力强很多 — 用另一个阵容选择«回退战斗»。如果不清楚情况 — 选择«手动通关»。回退需要花费时间（需要重新加载战斗，有时需要 20–30 秒甚至更久），而«忽略»不需要任何额外时间。

> [!done] 现在你了解了每个 SOS 窗口的含义、每个按钮的作用以及机器人无人在场时会做什么。接下来 — 了解当你不在电脑前时，机器人如何自行决定。[下一章节 →](#11)

## 机器人如何自行决定

在关于 SOS 窗口的章节中，你了解到了机器人在打得不好的战斗后会呼唤你。但它并非总是进行呼唤：如果开启«机器人自行决定»（«基础与房间»选项卡，第 7 节），机器人**会首先尝试自行解决**，只有在失败时才会寻求帮助。在这里我们将剖析它的思考逻辑。不会有复杂公式：只有机器人自问的问题和示例。

想象一个坐在你身旁拿着手机的经验丰富的搭档。战斗打得不好，而你离开去倒茶了。他不会傻坐着等待。他会回忆起之前针对这些敌人有效的方案，换个阵容重打，并记录下奏效的组合。机器人大概就是这样运行的。只是它遵循着一套规则，以防搞砸。

> [!note] «机器人自行决定»默认处于**关闭**状态，因此下文所讲的一切都不会发生：在每次打得不好的战斗后，机器人只会简单地打开 SOS 窗口。开启开关并点击«保存设置» — 将在下一次点击«开始刷»时生效。具体可以微调哪些设置，我们在第 8 节（“自动战术与生命值”）中讨论过，而这里讨论的是**机器人如何运用这些数字**。

### 打得不好的战斗：机器人按顺序做什么

1. **注意到战斗打得不好。** 有泰坦阵亡或低于恐慌门槛、损失超出了容许度、或者一下子有三人“垮掉”（第 7 和第 8 节）。日志中会记录带原因的 `[ТАКТИКА] Плохой бой: ...` 这一行。
2. **检查是否可以自行回退。** 在四种情况下无法自行回退：战斗为手动操作（安格斯大招，其结果窗口中没有“再试一次”按钮）、结果窗口读取失败、阵容是**你**设置的（决定权依然归你）或者机器人已用尽该房间的尝试次数。如果无法回退 — 打开 SOS 窗口，日志中记录带原因的 `[ТАКТИКА] Сам не откатываю: ... Спрашиваю вас.`。
3. **寻找备用阵容。** 如何寻找 — 见下一节。如果没有合适的 — 再次打开 SOS 窗口。
4. **回退并重打。** 执行与你选择相同的 `[ОТКАТ]` 步骤（“再试一次”、暂停、“撤退”），并在同一个房间上阵备用阵容。日志中记录 `[ТАКТИКА] Откатываю бой сам и переиграю паком ... (взят: ...)`。
5. **查看结果。** 备用阵容成功了 — 机器人继续前进，并且通常会记住该阵容（详见下文）。战斗依然不好 — 进行第二次尝试，以此类推，直到用尽尝试次数（«每个房间尝试的备用阵容数»，默认为 2，不超过 3）。之后再呼唤你。

> [!tip] 机器人每次都是回退整场战斗，而不是“实时纠错”。回退需要花费时间（必须重新加载战斗，有时需要 20–30 秒或更久），因此它不喜欢无意义的尝试：请参阅下文了解它如何选择阵容。

### 机器人从何处获取备用阵容

它会从上到下扫描列表，并选取**第一个合适的**：

1. **你的«备用阵容»** — «基础与房间»选项卡，房间卡片。按你排列的顺序依次获取。在日志中该来源被称为“ваш список запасных паков”。
2. **来自该元素规则的阵容** — 日志中称为“правила стихии”。内部有其自身的顺序：首先是“针对这些敌人”的规则，然后是曾经击败过这些敌人的阵容（按剩余生命值较高的优先），接着是其他“针对性阵容”，最后是包括房间基础阵容在内的其他所有阵容。
3. **战斗历史记录** — 日志中称为“история боёв”。这是最后的优先顺序，且仅选取曾经击败过这些敌人的阵容。机器人会记住最近 20 次启动的战斗记录。

机器人**绝不会**作为备用上阵的阵容：

- 已经在该房间输过的阵容（不犯重复错误）；
- “对此敌人会输”的阵容：上次针对他们时因敌人的原因回退了战斗，且该阵容的胜场不大于败场。单次失败**不会毁掉一个好的阵容**：如果它针对这些敌人赢了五次输了一次，机器人依然会选用它；
- 包含被“Skip”规则禁止的泰坦的阵容；
- 包含生命值已**低于恐慌门槛**的泰坦的阵容：机器人不会将其送入战斗去送死；
- 来自历史记录中 — 包含你未在任何地方（阵容或规则中）指定的泰坦的阵容。历史记录中会保留很久以前删除的规则的阵容，机器人不会复活它们。

此外还有“危险”阵容：根据以往战斗判断，带伤泰坦撑不到战斗结束的阵容。机器人会在**最后顺位**才选用它们，前提是没有任何更好的选择。它如何判定这一点 — 详见下文“带伤泰坦”部分。

机器人为什么没有选用某个阵容，可以在日志中看到：`[ТАКТИКА] Не беру запасной пак ...` 以及原因。如果备用阵容用尽且战斗依然不好 — 这不是故障，而是诚实的“我不知道还能上什么阵容”。

### 是否记住：规则“自动：…”

备用阵容成功了。机器人会将其记录在规则“针对这些敌人 — 上阵此阵容”中，下次遇到相同的敌人阵容时将直接上阵它。在列表中，此规则显示为«自动：房间里有 {names}»，并排在第一位（第 9 节）。日志中记录：`[ТАКТИКА] Запасной пак ... справился. Запоминаю его против этих врагов.`。

但也有些情况**不能记住**。示例：阿拉吉带着 36% 的生命值参战并掉到了 5%。基础阵容没有错：如果阿拉吉健康，战斗本可以正常通过。如果机器人记录下“针对这些敌人上阵备用阵容”的规则，它就会在基础阵容完全能胜任的地方开始上阵备用阵容，白白浪费你的战斗力。因此机器人会检查：**“如果所有人都是 100% 生命值，战斗还会打得不好吗？”** 如果不会 — 说明与敌人无关，这只是一次性帮助，不会创建规则。

在日志中可以立刻看到：`[ТАКТИКА] Враги ни при чём: в бой вошли раненые ...` 随后记录 `Правило не запоминаю: это была разовая помощь раненым титанам`。

在另外三种情况下也无法记住：

- 机器人未识别出敌人（`[ОБУЧЕНИЕ] Враги не распознаны — правило не сохраняю`）：没有敌人的规则会在任何房间触发；
- 你通过开关关闭了包含相同阵容的规则：被关闭的规则机器人不会触碰；
- 阵容是你亲自选择的：此时由你的«阵容成功了»窗口决定（第 10 节）。

### 带伤泰坦：提前帮助，而不是事后弥补

机器人最有价值的能力是 — **防止打出不好的战斗**，而不是事后收拾残局。当还在队伍选择界面时，它会查看泰坦的生命值和历史记录：“在这个房间用这个阵容战斗的结果如何？” 为此，机器人会存储泰坦在使用该阵容战斗时通常**损失**多少生命值（最近五场战斗的平均值，至少需要两场战斗）。如果带伤参战的泰坦的生命值减去常规损失后**将低于恐慌门槛** — 机器人不会冒这个险，而是在战斗前就直接上阵备用阵容。

示例：带着 36% 生命值的阿拉吉进入火元素房间。在最近的战斗中，它在这里通常会损失约 29% 的生命值。计算结果：36 − 29 = 7%，而恐慌门槛是 40。战斗几乎肯定会打得很糟糕，因此机器人会**立即**上阵备用阵容（例如包含摩洛克的阵容）。这是一次性帮助，不会记住规则。

为了不让机器人显得奇怪，有两个细节需要注意：

- **能量同样重要。** 如果泰坦当前的能量与之前的战斗相近（差异不超过 25%），机器人就会专门选取这些战斗来进行预测。满能量的阿拉吉在火元素中损失较少，空能量损失较多，预测会考虑到这一点。
- **一场战斗不构成统计。** 如果少于两场战斗，机器人不会相信预测，也不会做出改变。

救援规则的阵容（“如果阿拉吉低于 50% — 上阵西格德”，第 9 节）机器人不会提前替换：你设置它们正是为了照顾伤员，你的意图比它的预测更重要。

### 根据生命值选择门

如果机器人自行决定，且走廊里可见**几扇允许进入的门**，它不仅会按顺序选择（第 8 节，“门的优先级”），还会顾及带伤泰坦：

1. 首先进入**能够治疗伤员**的门：触发你的救援规则，或者机器人自己组建治疗阵容。
2. 根据以往战斗判断带伤泰坦可能面临危险的门，如果有其他选择，机器人会**跳过**。
3. 否则一切按常规顺序进行。

可通过 `[НАВИГАЦИЯ] Выбрана комната ... по здоровью титанов: ...` 这行日志查看。被“Skip”规则禁止的门，机器人依然绝不会打开。门后面的敌人机器人此时还看不到，因此这里它依赖的是该门的基础阵容。

### “混合”房间中的治疗阵容

如果伤员可以被治疗，而你的治疗规则没有触发，机器人会**自己组建治疗阵容**：将伤员以及必要时将健康且充满能量的治疗者放入“混合”房间。一次治疗一人，优先基础泰坦再到备用泰坦，而低于恐慌门槛的泰坦则完全不予治疗。所有细节（«生命值低于此值时治疗泰坦（%）»门槛、«为伤员从阵容中移除谁»，以及为瑞格尔准备的西格德） — 详见第 8 节。这里只需明确一点：这与基于预测的备用阵容一样， shared 都是**一次性帮助**。之后不会创建规则，并且在总结中会单独统计（“治疗阵容（机器人自行组建）”）。

### “黄金规则”：机器人根据整个历史记录学习

所有这些决定都是机器人在游戏过程中做出的。而“黄金规则”则是在**每次启动刷关时汇总一次**。机器人会查看战斗历史记录，寻找针对同一敌人组合打了 **5 场及以上且胜率达到 80% 及以上**的阵容。它会将这样的阵容记录为«黄金：房间里有 {names}»规则（第 9 节）。日志中记录：`[ОБУЧЕНИЕ] ...: 'Золотое правило против: ...' — пак ... Сохранено на 1-е место.`。

以下情况不会成为黄金规则：

- 房间的基础阵容、救援规则阵容以及你的«备用阵容»（它们用于援助，而不是每场战斗都用）；
- 机器人自行组建的治疗阵容：它们仅在泰坦受伤时需要；
- 包含在你所有阵容和规则中均未出现的泰坦的阵容；
- 针对已经存在对应规则（你的规则、“自动”规则或已关闭的规则）的敌人的阵容。

在关闭«机器人自行决定»期间，不会生成黄金规则。出现了不理想的规则？请**使用开关将其关闭**，而不是删除它：删除的规则会在下次启动时恢复，而关闭的规则机器人则不会触碰。

### 如果你未对 SOS 窗口作出回答

这不再是“机器人自行决定”，而是“机器人替你决定”（第 10 节，“如果不回答会怎样”）。即使在关闭«机器人自行决定»时该功能也有效：当超时后（«SOS 窗口无人应答的超时（分钟）»），机器人会使用备用阵容回退战斗、接受战斗或进入软暂停。每次它都会记录 `[ТАКТИКА] Ответа нет N мин. Решаю сам.`，关闭窗口并向 Telegram 发送消息。

### 如何了解机器人在无人在场时做了什么

在会话结束时，在«会话总结»区块（«详情»按钮）以及 `[ИТОГ]` 行中有相关计数器：

- **“撤回”**：总共重打了多少场战斗；
- **“其中无人干预”**：这些回退中有多少是机器人自行完成而未询问你的（包含根据预测和超时处理的）；
- **“治疗阵容（机器人自行组建）”**：它使用治疗阵容为伤员治疗的次数。

同样的总结也会发送到 Telegram：“撤回：6（机器人自行：5）”。如果“无人干预”占了绝大多数，说明机器人应对良好。如果该数字不断增加而“黄金规则”却没有生成，说明同一批敌人一次又一次打破了你的基础阵容。请查看«规则与拦截»选项卡了解它记住了哪些规则，并思考是否到了更换基础阵容的时候。

> [!warning] 机器人是根据**历史记录**和预测来做决定的，而不是能够预知未来战斗。它可能会犯错：在前几天历史记录较少时，备用阵容是随机挑选的。如果前几十个房间«机器人自行决定»回退的频率比预期的要高，不必惊慌。历史记录中的战斗越多，选择就越精准。

> [!tip] 从哪里开始？为每个房间至少设置一两个«备用阵容»（第 7 节）：这样机器人就不会盲目寻找。开启«机器人自行决定»，观察几天 `[ТАКТИКА]` 日志行和«会话总结»即可。如果不喜欢机器人的表现 — 关闭开关，一切就会恢复到 SOS 窗口模式。

> [!done] 现在你了解了机器人何时以及如何在无人在场时自行应对、它会记住什么以及何时呼唤寻求帮助。接下来 — Telegram：如何在离开电脑时接收消息。[下一章节 →](#12)

## Telegram

当你不在电脑旁时（比如去了厨房、去睡觉或外出上班），机器人可以通过 Telegram 给你发送消息。如果战斗需要你的帮助，聊天框中会收到一张截图和若干按钮。只要在手机上按一下按钮，机器人就会按照你的指示操作。如果一切顺利，机器人会保持安静：消息**仅在出现问题时**以及**在运行会话结束时发送一次**。

所需条件：Telegram 应用程序和 5 分钟时间。只需设置一次即可。

> [!note] Telegram 是可选功能。没有它，机器人依然可以正常运行，只是 SOS 窗口仅显示在电脑屏幕上，且不会收到会话总结。但如果你打算让机器人夜间运行，建议进行设置：这样你可以即时得知问题，而不是等到早晨才发现。

### 需要准备的内容

你需要准备两样东西，均可在 Telegram 内部获取：

- :send: **机器人令牌**（程序登录你机器人的密钥）。这是一串由数字和字母组成的长字符串，例如 `123456789:AAH…`。令牌由官方专门的机器人 **@BotFather** 提供。
- :user: **Chat ID**（聊天 ID）。这是一个数字，Telegram 通过它明确将消息发送给你而非其他人。

> [!warning] 令牌就相当于你机器人的密码。切勿向任何人展示、切勿在截图或邮件中发送（即使是程序开发者也不行）。在对“Telegram 设置”窗口截图时，请确保令牌已被圆点遮挡。

### 操作步骤

1. **创建你自己的机器人** — 在 Telegram 中搜索 **@BotFather**（真实的账号带有蓝色对勾标记），点击“开始”。向它发送 `/newbot`，起一个名称（可以是任意名称，只有你能看到）以及一个以 `bot` 结尾的用户名（例如 `moi_titan_bot`）。BotFather 会回复一条包含令牌的消息：将其复制下来。
2. **获取你的 Chat ID** — 搜索机器人 **@getmyid_bot**，点击“开始”，它会回复一行 `Your user ID` 及一串数字。这就是你的 Chat ID，将该数字复制下来。如果该机器人无响应，可使用备用方法：向第 1 步中**你自己**创建的机器人发送任意文字，然后在浏览器中打开地址 `https://api.telegram.org/bot<твой токен>/getUpdates`（将 `<твой токен>` 替换为实际令牌），在返回内容中找到 `"chat":{"id":` —— 紧随其后的数字即为 Chat ID。
3. **在你自己的机器人中点击“开始”** — 找到你在第 1 步创建的机器人，点击“开始”（或向其发送 `/start`）。如果不执行此操作，Telegram **将不允许**机器人主动向你发送消息。这是导致收不到消息的最常见原因。
4. **打开程序中的窗口** — 点击左侧栏上的 Telegram 圆点，或点击“基础与房间”标签页（第 7 节）中的**“设置 Telegram”**按钮。此时将打开“Telegram 设置”窗口。
5. **填写信息** — 勾选“向 Telegram 发送消息”开关。在“机器人令牌（来自 @BotFather）”字段中粘贴令牌，在“聊天 ID”字段中粘贴数字。最方便的方式是使用字段旁边的**“粘贴”**按钮：它会自动获取剪贴板中的内容。令牌默认以圆点显示，点击眼睛图标可以取消隐藏，以便核对粘贴是否正确。在字段上右键单击也可以选择“粘贴”。
6. **测试连接** — 点击**“测试 Telegram”**。几秒钟后，右侧将显示绿色的“消息已发送——请查看 Telegram”，同时在你与机器人的 Telegram 聊天框中会收到消息“连接测试：一切正常”。收到消息即表示设置成功。
7. **保存设置** — 点击**“应用”**，然后点击页面底部的**“保存设置”**。

![“Telegram 设置”窗口：开关、令牌和聊天 ID 字段、“粘贴”与“测试 Telegram”按钮](images/telegram_window.png)

> [!warning] “应用”仅是将数值传递到“规则大师”页面，并**不会写入文件**。在点击“保存设置”之前，底部会持续提示“有未保存的更改”，且机器人完全无法使用 Telegram。如果你未保存就离开该页面，程序将询问“保存更改？”。

> [!tip] “测试 Telegram”用于测试当前窗口中填写的内容，即使你尚未保存。因此请在点击“应用”**之前**进行测试：发现错误 — 修改 — 再次测试。测试在后台运行，窗口不会卡死，且等待响应的时间不会超过 20 秒。

### 如果测试未通过

按钮下方会出现红色的错误提示“发送失败：...”。最常见的原因包括：

- **“请填写令牌和聊天 ID”** — 某个字段为空。
- `Unauthorized` — 令牌不正确：缺少字符、包含多余空格或未完整复制。请使用“粘贴”按钮重新粘贴。
- `chat not found` 或 `Forbidden` — Chat ID 不正确，或者你尚未在**你自己的**机器人中点击“开始”（第 3 步）。请检查这两项。
- **“Telegram 通讯故障”** — 网络未连接或从当前电脑无法打开 Telegram。请检查该电脑上 Telegram（或 telegram.org 网站）是否可以正常访问。

如果在修改后依然无法收到消息，请在 @BotFather 处重新创建一个新的机器人（第 1 步）并从头开始：这比排查拼写错误要快得多。

### 如何确认 Telegram 已开启

在左侧栏的 Telegram 按钮旁有一个圆点：将鼠标悬停在其上，会显示提示**“Telegram：已开启”**或**“Telegram：未设置”**。已开启意味着开关已打开且两个字段均已填写。这**不是连接测试**：令牌是否有效只能通过点击“测试 Telegram”按钮来确认。在“基础与房间”标签页中也可以看到相同的信息：在“设置 Telegram”按钮旁会显示绿色的“SOS 通知已开启”或灰色的“Telegram 未设置”。保存后，圆点会在几秒钟内自动更新。

### 发送的消息内容

消息使用的语言与程序窗口中所选的语言一致。

- :swords: **SOS 窗口** — 标题为“需要你的帮助”（或“没有合适的阵容”），附带游戏截图及说明文本：房间、敌人（进攻目标）、原因以及带生命值和能量条的当前阵容。底部附带操作按钮。这与电脑窗口上弹出的问题完全相同（第 10 节）。
- :triangle-alert: **警报** — 不带按钮的简短消息，说明发生了什么以及该怎么做。具体包括：“撤回战斗失败”（机器人处于软暂停状态，请查看手机屏幕）、“机器人似乎卡住了”（5 分钟未进入任何房间）以及无法开始战斗时的类似消息（很可能是与游戏服务器断开连接）、“电脑屏幕已锁定”（机器人超过一分钟未检测到游戏；解锁电脑后机器人将自动继续运行）以及“你没有回应 — 机器人已自行决定”。
- :chart-no-axes-column: **运行总结** — 当机器人停止时发送：累计耗时、经过的房间数、层数和泰坦石数量、是否存在撤回和 SOS 窗口（“机器人自行：N”表示机器人未经你干预自行完成的撤回次数）以及耗时最长的房间。如果机器人因错误而中断，标题中将显示“机器人因错误停止”及具体原因。

无论因何种原因停止，都会发送总结：已达到目标、按下了 Ctrl+Q 或 Ctrl+Shift+Q，或者机器人因错误崩溃。但在按下“STOP F10”或点击“停止并关闭”（第 6 节）后**不会发送**总结，因为这些操作会立即强制终止机器人。

### SOS 消息下方的按钮

在 Telegram 中点击这些按钮的效果与在电脑窗口中操作完全相同：

- **“回滚 (组建阵容)”**（绿色）。机器人将提示：“请在聊天框中输入 3-5 名泰坦的名称”。请在聊天框中使用逗号或空格隔开输入，例如 `гиперион, сигурд, нова`，也可以简写为名称前三个字母：`гип сиг нов`。机器人会回复识别到的泰坦并询问“确认无误？”：点击**“确认阵容”**将开始撤回并应用，点击**“重新输入”**可重新填写。如果识别到的泰坦数量不是 3 到 5 名，机器人会说明识别数量并请你重新输入。
- **“手动通关”**（蓝色）。机器人不会进行任何点击，静静等待你手动完成当前房间。
- **“忽略 (继续)”**（灰色）。接受当前战斗结果并继续推进。
- **“停止机器人”**（红色）。当战斗为手动模式（安格斯大招）或没有合适阵容时，该按钮将替代“回滚”。在“没有合适的阵容”窗口中没有“继续”按钮。

当你选择的阵容成功通关后，Telegram 中会收到“阵容成功了”的询问提示，并附带两个按钮：**“确认并保存”**（将该阵容保存为规则）和 **“回滚并重试”**（重新输入其他阵容）。仅当你也是通过 Telegram 发送阵容时，该提示才会发送到 Telegram 聊天框中。

点击后，消息下方将只留下一条绿色的“已选择：...”按钮，其余按钮消失。只能响应**一次**：机器人不会接收针对旧消息的多次点击。如果你在 Telegram 聊天框中进行了回复，电脑上的窗口会自动关闭；如果你在电脑上进行了回复，机器人将停止等待 Telegram 的响应。

> [!tip] 在你找手机时机器人已经自行做出了决定？没关系。系统会发送一条消息“你没有回应 — 机器人已自行决定”，旧消息上的按钮将不再生效。机器人的等待时间可在“自动战术”中设置（第 8 节，“SOS 窗口无人应答的超时（分钟）”）。

### 如果网络连接中断

机器人不会停止，也不会等待 Telegram：消息是在后台发送的。如果因网络原因发送失败，它会在 **30 秒、1 分钟、2 分钟、5 分钟和 10 分钟**（总计约 18 分钟）后重试，并且在日志中可以看到 `Сообщение в Telegram не ушло (...). Пробую снова через N с.`，最后显示 `Сообщение в Telegram: отправлено с N-й попытки`。SOS 窗口也是同理：它会保留在电脑屏幕上，当网络恢复时，问题会自动发送到 Telegram。运行总结的重试频率更短（10 秒和 30 秒），因为总结发送后机器人就会关机。Telegram 本身的错误（如令牌无效）机器人不会重试：这些需要在设置中进行修正。

> [!note] 机器人不会“随时”接收你的指令（例如从聊天框中停止或暂停）。Telegram 仅用于回应机器人主动提出的问题。无法直接从聊天框中停止机器人，除非点击 SOS 消息下方的“停止机器人”按钮。

> [!done] Telegram 设置完成，现在无论你在哪里，机器人都能向你求助了。接下来是统计数据：按日期统计的房间数、层数和泰坦石数量。[下一章节 →](#13)

## 统计

“统计”页面解答了“我打了多少？”的问题：一周、一个月和全部时间内积累了多少钛晶、房间数、层数和泰坦药水。通过左侧栏上的 **«统计»** 按钮打开，顶部写着“活动统计”。

这些数字是机器人**自己计算的**，而不是从游戏屏幕上读取的。通关一个房间 — 记录：**6 钛晶和 25 药水**，如果结算窗口有“x2”标志 — 则是 **12 钛晶和 50 药水**。在存档点获得奖励 — 记录层数。你手动通关且被机器人计入的房间（第 10 节），它也会记录。总结存放在 `bot_data/stats.json` 文件中，并“按游戏天”保存。

> [!note] **游戏天**不是从午夜开始，而是在你在 «规则大师» 中设定的重置时间开始（默认为 5:00，第 7 节）。因此，机器人在凌晨 02:30 收集的所有内容都记入**昨天**：此时游戏中仍算作昨天。如果早晨 «钛晶（今天）» 为零，尽管你夜间玩过，这也是正常的。

### 页面内容

左上方是提示，右侧是 **«时间段»** 选择，下方是五个卡片、图表以及底部的 «手动校正»。

- :calendar: **时间段** — «7 天»、«14 天»、«30 天» 或 «全部时间»。选中的项目显示为蓝色。首次打开时默认为 «14 天»。
- :gem: **«钛晶»** — 该时间段内的总和。
- :calendar: **«钛晶（今天）»** — 仅限当前游戏天。不受时间段影响。
- :flask-conical: **«泰坦药水»**、:door-open: **«房间»** 和 :layers: **«层»** — 该时间段内的总和。

卡片中不超过 100 000 的数字会完整显示（`98 540`），而较长的数字会被缩写：`105.5K` 表示一万零五百五十，`1.24M` 表示一百二十四万。将鼠标悬停在卡片上即可显示完整数字。«全部时间» 从文件中获取总计数器，而不是柱状图的总和，因此即使柱状图很多，卡片也能与历史记录保持一致。

> [!tip] 页面在**每次打开时**读取数字，而不是在游戏过程中实时读取。机器人正在运行但数字没有变化？切换到其他页面再返回即可。

### 图表：柱状图与点击

在“钛晶活跃度”标题下方说明了柱状图的汇总方式：「按天」、「按周」或「按月」。柱状图不超过 15 个，以免图表过于拥挤：

- **7 天和 14 天** — 每个柱状图代表一天。
- **30 天** — 按周（周一至周日；两端的周可能不完整 — 仅包含落入该时间段的日期）。
- **«全部时间»** — 数据少于两周时按天；之后按周；当周数超过 15 个时按月。

左侧是带虚线网格的刻度，刻度上的数字很短（`3.6K`、`140K`）。如果柱状图下方的标签放不下，会隔一个显示；最后一个（今天的）始终可见。没有游戏的日子留空，没有柱状图。对于没有数据的时间段，图表会显示 «此时间段没有数据»。

1. **将鼠标悬停在柱状图上。** 上方会出现钛晶的精确数值。这只是提示，不会改变任何内容。
2. **点击柱状图。** 它会变亮，其他柱状图变暗，旁边会出现带有日期和数值的浮条。对于按周的浮条，会**按天**列出钛晶，按月的浮条则**按周**列出。左上方会亮起蓝色标签，例如 «显示日期：19.10.2026 · 今天»（或“显示周”、“显示月”）。
3. **查看卡片。** 它们现在显示该柱状图的数字：当天、当周或当月的钛晶、药水、房间数和层数。«钛晶（今天）» 保持为当前值。
4. **返回总览。** 再次点击同一个柱状图，或点击带叉号（✕）的蓝色标签。切换时间段也会重置选择。

### 手动校正

机器人按自己的算法计算（每个房间 6 或 12 钛晶），但游戏中的数字可能不同：你亲自玩过、机器人关闭过、程序没有从早晨就启动。为了使统计数据与游戏一致，提供了 **«手动校正»** 卡片。

1. **选择日期。** 列表中有“今天”、“昨天”以及过去 5 天，共 7 天。需要更早的日期？选择时间段 «7 天» 或 «14 天» 并点击其柱状图：该日期会自动填入列表中（按周和按月的柱状图不会填入 — 仅按天的会）。
2. **填入游戏中的总数字。** 在 «当天钛晶» 字段中填入游戏里显示的**整天总数**，而不是“要添加多少”。对于选定的日期，已填入当前记录的数值。
3. **点击 «应用»**（或在字段中按 Enter）。

示例。机器人当天记录了 90 钛晶，而游戏里当天是 150。你输入 **150** — 程序会添加 60 的差值并自动重新计算其余数据：约 **+5 房间、+1 层 和 +250 药水**。这是一个估算值：假设当天的前 10 个房间各给 6 钛晶，其余各给 12。如果你玩法不同，房间数和层数可能与实际略有出入，但钛晶数会与你输入的一模一样。

成功后，底部会显示通知 «19.10.2026 的钛晶：150»，主页日志中将记载 `[СТАТИСТИКА] Данные за 2026-10-19 синхронизированы! Дельта: +60 тит., +5 комн., +250 зелий.` 如果输入的数字少于记录值，数字将会减少。

可能出现的问题：

- «请输入不小于 0 的整数» — 字段中有字母、逗号、减号或为空。字段将变红。
- «机器人当天自己收集了 90，不能填写更少» — 不能填写少于机器人**自己**收集的数值，因为那是如实记录的。数字最多只能降低到该值。
- «当天已是这个数值» — 你输入了相同的数字，无需更改。

> [!warning] «应用» 会**立即**将数字写入 `bot_data/stats.json`。这里不需要也不存在 «保存设置» 按钮（与第 7 节中的 «规则大师» 不同）。无法通过按钮撤销修改，但重新输入原来的数字没有任何限制。

> [!note] 校正**仅改变统计数据**。主页上的“会话总结”和会话目标（第 4 节）是根据本次运行中机器人的收集情况单独计算的，不受“统计”页面的影响。

### “重置”：清除所有历史记录

**«重置»** 按钮（带垃圾桶图标，位于 «手动校正» 卡片右侧）将清空所有统计数据：所有日期的钛晶、房间数、层数和药水。误点了？不会发生任何事：程序首先会询问 «重置统计？» 并提醒此操作无法撤销。在窗口中点击 «重置» 按钮确认，点击 «取消» 按钮放弃。重置后会出现通知 «统计已重置»，日志中显示 `[СТАТИСТИКА] Вся история полностью сброшена!`。

仅清除统计数据。规则、阵容、设置、`profile.yml` 和战斗日志均保留。如果机器人此时正在运行，它将继续运行并从零开始重新计算，会话目标不会被打乱。

> [!tip] 想“试着重置”一下？请先保存副本：关闭程序并将文件 `bot_data/stats.json` 复制到其他地方（通过“关于”页面上的 «机器人文件夹» 按钮打开程序文件夹）。将文件放回原处即可恢复历史记录。

### 常见问题

- **数字与游戏不符。** 机器人是进行计算而非读取屏幕：每个房间 6 或 12 钛晶。如果你从其他来源获得了钛晶，游戏中显示的数字会更多。请进行对比并通过 «手动校正» 进行修正。
- **今天的数据是空的，但我玩过了。** 请检查重置时间：在该时间之前，机器人都会记录到“昨天”（参见上文“游戏天”）。在 «规则大师» 中更改了时间？请重启程序以便页面重新读取。
- **柱状图很少但时间段很大。** 机器人未工作的日子在图表上留空。«全部时间» 和月份默认会压缩图表：要查看具体日期，请选择 «7 天» 或 «14 天»。
- **日志中显示 `[СТАТИСТИКА] ВНИМАНИЕ: Файл stats.json поврежден`。** 包含历史记录的文件无法读取（例如在写入瞬间电脑断电）。机器人将从零开始新的统计并覆盖该文件。如果旧历史记录很重要，请提前进行备份。

## Если что-то пошло не так

好消息是：机器人知道如何自己摆脱大多数麻烦。卡住了 — 它会观察四周并重新开始。网络断了 — 它会等待。电脑锁屏了 — 它会停下来然后继续。只有当它**亲自请求**（进入暂停、在 Telegram 中发消息），或者它什么都没按而日志里看不出原因时，才需要你。本节涵盖这两种情况：机器人在没有你的情况下会做什么、如何判断故障出在哪里以及该按什么。

适用于所有情况的原则：**不要惊慌，不要着急**。停止机器人、重启并重新运行并不可怕：统计数据、阵容、规则和设置都保存在文件中，不会丢失。

### 如何判断出了问题

- :triangle-alert: **主界面日志中“错误”胶囊上的红色数字。** 它计算的不只是故障：警告（例如“游戏窗口被遮挡”）也会算在这里。数字本身并不是害怕的理由，你需要打开胶囊阅读具体内容。
- :pause: **处于“已暂停”状态且显示绿色“继续”按钮，虽然你并没有按暂停。** 这意味着机器人自己停了下来并等待你。此时日志中会有一行说明原因的 `[ВНИМАНИЕ] Бот на мягкой паузе: ...`。
- :send: **Telegram 中的消息**（如果配置了 Telegram，见第 12 节）：“机器人似乎卡住了”、“撤回战斗失败”、“电脑屏幕已锁定”。
- :eye: **静默。** 日志中一分钟或更长时间没有新行出现，而游戏中什么也没发生。这也是一种迹象：请参阅下文的“常见情况”一节。

日志中表明存在问题的标记：

- `[СТОРОЖ]` — 机器人判定自己卡住了，并自行重新开始。
- `[СЕТЬ]` — 似乎与游戏服务器失去连接。
- `[ЭКРАН]` — 电脑无法截屏（已锁定）。
- `[ОТКАТ]` — 战斗撤回步骤及其错误（第 10 节）。
- `[ВНИМАНИЕ]` — 机器人请求注意：暂停、游戏窗口已关闭。
- `[ОШИБКА]` — 出了某些故障；旁边写明了原因。
- `[ADB]` 和 `[VISION]` — 与手机的连接和点击。

### 机器人自己会做什么

在这里你不需要按任何按钮。只需知道这是正常的，不会破坏会话。

- :gauge: **卡住：5 分钟未通过任何房间。** 这是“看门狗”（监控机器人是否卡住的检查程序）。机器人打印 `[СТОРОЖ] Бот 5 мин не прошёл ни одной комнаты ... Тревога 1 из 3.`，保存截图，发送 Telegram 消息（如果已配置）并执行**“智能启动”**：重新观察屏幕并决定从哪里继续。如果没起作用，5 分钟后再次报警。**连续三次报警**（即大约 15 分钟没有通过房间）— 机器人进入软暂停并等待你。机器人等待你的时间（SOS 窗口、暂停、覆盖在游戏上的其他窗口），看门狗是不计算在内的。
- :activity: **卡在同一个地方。** 队伍选择屏幕 30 秒内未出现，或结算窗口 3 分钟内未出现。此时会记录 `[СТОРОЖ] Зависание: ...`、保存截图并进行相同的智能启动，但不会在 Telegram 中报警。
- :globe: **战斗未开始（极可能是与游戏服务器失去连接）。** 已点击“自动”按钮，但战斗未开始。机器人会立即再试两次，然后等待并再次尝试：分别在 30 秒、1 分钟、2 分钟、4 分钟和 8 分钟后。所有这些都会在日志中显示为 `[СЕТЬ] Бой не начался N раз(а) подряд ... Жду N с и пробую снова.`。如果这样还没解决（约 15 分钟）：保存截图，提示消息“机器人似乎卡住了”并进入软暂停。
- :rotate-ccw: **战斗撤回期间失去连接。** 机器人不会放弃，而是**最多等待游戏 15 分钟**：打印 `[ОТКАТ] Бой не загрузился ... Не сдаюсь`，保存截图并每分钟提示 `Всё ещё жду игру`。连接恢复后 — 撤回将自行完成（`Игра снова откликается`）。15 分钟内未恢复 — “撤回战斗失败”，发送 Telegram 消息并暂停。
- :monitor: **电脑已锁定 (Win+L) 或屏幕已关闭。** Windows 不允许截图，机器人什么也看不见。它**不会崩溃**，而是每 2 秒重试一次：`[ЭКРАН] Не удаётся сделать снимок экрана ... Похоже, ПК заблокирован`。超过一分钟 — 发送一条消息“电脑屏幕已锁定”。解锁后 — `[ЭКРАН] Снимок экрана снова работает`，机器人自行继续。
- :layers: **游戏窗口被其他窗口遮挡。** 机器人等待其再次成为主窗口（`[ВНИМАНИЕ] Окно игры перекрыто ... Бот ждет фокуса`）。点击一下游戏窗口，它就会继续。原因详见第 5 节。
- :target: **点击未送达。** 如果点击 4 秒后屏幕未发生变化，机器人会再次点击：`[VISION] Клик по '...' не зарегистрирован сервером ... Повторяю...`。偶尔出现这种行是正常的：手机有时会“思考”。
- :smartphone: **通过线缆与手机的连接闪断。** 机器人打印 `[ADB] Постоянное соединение с телефоном оборвалось ... Переподключусь при следующем нажатии` 并重新连接。
- :send: **由于网络问题，Telegram 消息未发送。** 机器人稍后会重试（第 12 节）并继续工作。

> [!note] 会话期间机器人卡住的次数可以在日志中的 `[ИТОГ]` 模块中看到（包含“зависания”一词的行）。偶尔发生不是什么大问题。如果频繁发生，请在下文的“常见情况”一节中寻找原因。

### 机器人自己暂停了：该怎么办

它停了下来，是因为没有你就无法继续。请按顺序操作：

1. **观察游戏屏幕** — `HeroWarsBot_Arena` 窗口会显示机器人卡在什么地方：结算窗口、战斗中、暂停菜单、加载中的“小蘑菇”或是某种意外情况（其他窗口、广告、游戏弹窗请求）。
2. **阅读日志的最后几行** — 打开“错误”胶囊并查看底部：那里指出了机器人停止的原因（`[СТОРОЖ]`, `[ОТКАТ] ОШИБКА`, `[СЕТЬ]`)。
3. **将游戏返回地牢走廊** — 关闭多余界面，等待战斗结束或加载完成，回到带有门和旗帜的屏幕。
4. **点击“继续”** — 机器人将重新观察四周（智能启动）并继续前进。

> [!note] 撤回失败后的暂停也可能是这种情况：手动战斗已经结束，结算窗口上不再有“再试一次”，因此无法撤回。结算窗口留在屏幕上 — 无需关闭任何东西，点击“继续”后，机器人自己会点击“确定”。在此窗口上查看谁存活了起来。

> [!tip] 机器人并不是遇到每件小事都会暂停，而是在尝试过但失败后才会暂停。因此，在点击“继续”之前，请弄清楚**究竟**出了什么问题。如果原因依然存在（无网络、游戏已关闭），机器人在几分钟后会再次暂停。

### 常见情况：查看什么以及该怎么做

**机器人什么都不按，日志中很安静。** 很可能它看不到游戏或无法在其中找到任何东西。请按顺序检查：

1. **游戏窗口就在原处** — 它叫作 `HeroWarsBot_Arena`，未最小化且未关闭。如果窗口不存在，机器人不会为此记录日志，而是每半秒默默地检查一次。因此，窗口消失时日志安静是正常现象。点击“连接手机”：窗口将重新打开。
2. **窗口大小未改变** — 机器人在启动时测量一次窗口，之后一直使用该尺寸。启动后拉伸、最大化或移动了窗口 — 请停止机器人 (F10)，点击“重置游戏窗口大小”，然后再次点击“开始刷”。详情见第 3 节。
3. **游戏中是地牢走廊**，而不是菜单、商店、其他活动或广告窗口。
4. **程序语言与游戏语言一致**（左侧条底部的两个字母）。否则机器人将无法识别按钮。
5. **没有东西遮挡游戏窗口。** 游戏上方有任何窗口 — 机器人都会等待焦点。

**机器人“看到”并点击了，但游戏中什么也没发生。** 日志中接连出现“Клик по ... не зарегистрирован сервером ... Повторяю...”。这意味着点击命令未送达手机。请检查：

- 手机上是否启用了**两个**调试设置：“USB 调试”和“USB 调试（安全设置）”。如果没有开启第二个，虽然有画面但点击不起作用（第 2 节）。
- 手机已解锁，线缆插紧。尝试使用另一个 USB 接口。
- 在命令行中，`adb devices` 在手机旁边显示 `device`，而不是 `unauthorized` 或空列表。
- 如果没有帮助：停止机器人，点击“重启 scrcpy”，然后点击“开始刷”。

**机器人按错地方或混淆了泰坦。** 最常见的原因是游戏窗口尺寸不对，或者启动后动过窗口（同上，重置尺寸）。尺寸正确但机器人仍然按错 — 保存该时刻的截图，并与日志一起发送给作者（见下文）。

**程序窗口“无响应”。** 程序会自我监控：如果窗口 5 秒内无响应，它会写入文件记录卡在代码的哪一行。文件位于 `bot_data/debug/`，名为 `ui_freeze_<дата>_<время>.txt`。该怎么做：

1. **等待一分钟** — 窗口经常会自行恢复：它正忙于繁重的任务。
2. **机器人与窗口独立运行** — 需要停止机器人但按钮无响应？按下 Ctrl+Shift+Q：该快捷键由机器人本身监听，而不是程序窗口（第 6 节）。
3. **未恢复 — 点击叉号关闭窗口** — 无法关闭 — 通过任务管理器 (Ctrl+Shift+Esc)。然后在那里检查列表里是否还留有 `HeroWarsBot.exe` 或 `python`：如果有，也将其关闭，否则机器人将在没有窗口的情况下继续在游戏中点击。
4. **把 `ui_freeze_...txt` 文件发给作者** — 那里只有文件名和程序代码行号，没有任何个人隐私。

**机器人停止了，但你并没有停止它。** 打开主页上的“会话总结”卡片（“详情”按钮），查看原因：

- “scrcpy 窗口已关闭” — 游戏窗口被关闭或消失了（拔掉了线缆、手机锁屏了）。请重新连接手机。
- “机器人已结束运行” — 进程无原因结束。如果配置了 Telegram，总结已发送到那里；如果没有，请在日志中查找 `[ОШИБКА] Бот остановился из-за ошибки:` 一行及其下方的文本。
- “Пак не найден в правилах”（规则中未找到阵容）— 未为房间设置主力阵容。打开“规则大师” → “基础与房间”，并在所有四个房间中进行设置（第 7 节）。
- “Ошибка: ...”（错误：...）— 程序崩溃。请将日志发送给作者（见下文）。

> [!warning] 在点击“停止” (F10) 后，机器人来不及写入 `[ИТОГ]` 模块，也不会向 Telegram 发送总结：它是在运行中被强行终止的（第 6 节）。这不是故障。

**手机“休眠”或屏幕熄灭。** 程序在启动 scrcpy 时使用了“防止手机休眠”模式（`--stay-awake`）。“关闭手机屏幕”按钮只熄灭**屏幕**：游戏仍在运行，机器人能看到一切。但如果手机锁屏或断开线缆，游戏窗口中将显示锁屏界面或一片空白，机器人将找不到任何东西。请解锁手机，检查线缆，然后点击“重启 scrcpy”。

**未收到 Telegram 消息。** 最可能是没有在自己的机器人中点击“Start”，或者 Token/Chat ID 不正确 — 详见第 12 节。此时机器人仍像往常一样工作。

**机器人上阵了错误的泰坦，或做出的决定与你设想的不符。** 这不是故障，而是规则：请阅读第 7–11 节（阵容、阈值、规则、“机器人自行决定”）。机器人的决定总能在日志中的 `[ТАКТИКА]` 行中找到。

### 日志和截图保存在哪里

“关于”页面上的 **“机器人文件夹”** 按钮可打开程序运行所在的文件夹。其中包含机器人自己创建的文件。需要的内容在 `bot_data` 文件夹内：

- :file-text: `bot_data/logs/bot_log_<дата>_<время>.txt` — **机器人每次启动的完整日志。** 机器人自己逐行写入，因此即使在崩溃和程序关闭后依然保留。这是分析问题的主要文件。
- :gauge: `bot_data/logs/timings_<дата>_<время>.csv` — 每个房间耗费的时间（走廊、组队、战斗、结算）。
- :swords: `bot_data/logs/battle_log_<дата>_<время>.jsonl` 和 `battle_log.csv` — 战斗历史：房间、敌人、阵容、结果、泰坦的生命值与能量。
- :image: `bot_data/debug/` — **用于排查问题的截图。** 文件名说明发生了什么：`stuck_...` — 卡住，`sos_...` — SOS 窗口，`rollback_wait_...` — 撤回期间等待游戏，`rollback_fail_...` — 撤回失败，`start_fail_...` — 战斗未开始，`result_unreadable_...` — 无法读取结算窗口。接下来是房间号、元素和时间（`stuck_комната12_water_2026-10-19_14-03-21.png`）。如果程序窗口卡住，那里还会包含 `ui_freeze_...txt`。

> [!warning] 机器人会自动清理旧文件：启动时在 `bot_data/logs/` 中每种类型保留 20 个新文件（`.txt`、`.jsonl`、`timings_*.csv`），而在 `bot_data/debug/` 中保留 50 张新截图。如果你想保存出问题那一夜的日志，**请在下次启动机器人之前将它们复制到其他位置**。同样，你通过“保存日志”按钮保存到默认文件夹的日志也会被擦除：请将其保存到其他位置，例如桌面。

> [!warning] 请勿删除或重命名 `profile.yml`（你的设置和 Telegram）以及 `bot_data` 文件夹：其中包含统计数据、机器人记住的规则和战斗历史。只允许删除 `bot_data/debug` 和旧日志，且仅在不需要时删除。

### 如何把日志发给作者

当无法解决问题时，最快的方法就是将发生的事情发送给作者。

1. **记住发生的时间** — 时间和大致的房间数（`[СТАТИСТИКА] Комнат: N`）有助于在漫长的日志中找到所需的位置。
2. **找到文件** — 日志是那一夜的 `bot_data/logs/bot_log_...`，截图来自 `bot_data/debug/`（文件名中有类似的时间），如果是窗口卡住还有 `ui_freeze_...txt`。
3. **点击“把日志发给作者”** — 在主页日志下方点击。程序将提示保存当前日志中的内容（文件为 `gui_log_...txt`），然后打开你的邮箱并准备好发往作者地址的邮件。
4. **亲自将文件添加到邮件附件中** — 程序无法自动将文件附加到邮件中：它只能打开邮件界面。请附上 `gui_log_...txt` 或 `bot_log_...txt`、截图以及（如果有）`ui_freeze_...txt`。
5. **用文字说明** — 你做了什么、预期发生什么、看到了什么以及是什么时候发生的。单凭一句“不起作用”对作者几乎没有任何帮助。

> [!warning] **切勿附带** `profile.yml` 和 `bot_data/profile.yml.bak`：其中包含你的 Telegram 机器人的 Token。“Telegram 设置”窗口的截图也请仅在隐藏 Token（用圆点遮挡）后发送。

> [!note] 邮箱未打开（未配置邮件客户端）？在“关于”页面上有“联系作者”按钮：如果无法打开邮件，它会将地址复制到剪贴板，你可以从任何邮箱发送。

### 如果一切都无济于事

由易到难，每完成一步后检查机器人是否恢复正常：

1. **“已暂停” → 将游戏返回走廊 → “继续”。**
2. **“停止” (F10) → “开始刷”** — 机器人将从智能启动开始，自行搞清楚所在位置。
3. **停止机器人并点击“重启 scrcpy”** — 然后再次点击“开始刷”。
4. **关闭程序并重新打开** — 如果手机“卡死”，拔掉并重新插上线缆。
5. **重启电脑和手机** — 听起来像个玩笑，但能解决一半的奇奇怪怪的问题。

重启后会话目标（时间、房间数、楼层、泰坦石）将重新计算，而统计数据、阵容和规则依然保留：它们保存在文件中。

## О программе и поддержка

左侧菜单中的最后一个页面是“关于”。它是关于程序本身的：你使用的是哪个版本、一切是否在原位、在何处联系作者以及如何表达“感谢”。不需要在其上配置任何内容，但这里有两个非常有用的按钮：“检查更新”和“机器人文件夹”。

### Что на странице

- :shield-check: 顶部的**程序卡片**。名称为“Hero Wars: Knowledge Engine Bot”，旁边是**版本号**（例如 `v1.6.1`）和 `Beta` 标记。“Beta”意味着“正在实测中”：程序可以运行，但作者仍在改进它，可能会出现错误。名称下方是简短描述。右侧有四个按钮，详情见下文。
- :user: **“作者与许可证”**：作者姓名、其邮箱和许可证。点击邮箱地址 — 将打开邮件。
- :monitor: **“组件状态”**：检查电脑上是否有运行所需的一切。详情见下文。
- :heart: **“支持本项目”**：感谢作者的方式。这不是强制性的。

> [!tip] 在反馈问题时请向作者说明版本号：它能直接显示你使用的是哪个版本的程序。版本号位于顶部卡片中，紧挨着名称。

### Четыре кнопки в карточке

1. **“检查更新”。** 在浏览器中打开 GitHub 上项目的发布页面（GitHub 是作者保存程序的网站；“发布/release”是可供下载的成品版本）。在页面上将最新版本号与你的版本号进行对比。如果有更新的版本 — 可以更新；如果相同 — 说明你使用的是最新版本。
2. **“机器人文件夹”。** 在 Windows 资源管理器中打开启动程序所在的文件夹：即存放你的设置和数据的那个文件夹。在需要复制文件或查找日志时很有用。
3. **“联系作者”。** 在你的邮件程序中打开致作者地址的邮件。如果电脑上没有邮件程序，邮件将无法打开。届时程序会自动将地址放入剪贴板（可以通过 Ctrl+V 粘贴的临时内存），并在窗口下方提示：“无法打开，已复制到剪贴板”。你可以从任何邮箱将地址粘贴到邮件中。
4. **“项目 GitHub”。** 打开 GitHub 上的项目主页：那里有源代码和描述。

> [!note] 程序**本身不会自动联网获取更新**：“检查更新”仅打开页面，由你决定是否更新。这样设计的目的是确保在未经你许可的情况下不会更改任何内容。

### Как обновить программу

更新并不是“直接覆盖安装” — 你下载新版本并将自己的数据迁移进去。这样你的阵容和统计数据就不会丢失。

1. **停止机器人并关闭程序。** 如果机器人正在运行，点击窗口叉号会询问是否停止它。
2. **下载新版本**（在发布页面上，点击“检查更新”按钮），并解压到新文件夹中，不要覆盖旧文件夹。
3. **迁移你的数据。** 从旧文件夹向新文件夹中复制 `profile.yml` 文件和整个 `bot_data` 文件夹。如果没有它们，新程序将从“零”开始：空白设置和空白统计数据。
4. **启动新程序** 并查看“关于”：版本号应当是最新的，且所有三个组件都应处于正常状态。
5. **暂勿删除旧文件夹。** 在新版本上运行几天。一切正常 — 再将其清理。

> [!warning] 不要逐个复制 `bot_data` 中的“所需文件”，而是要迁移整个文件夹：机器人自行记住的规则、战斗历史和统计数据是相互关联的，无法重新组装。

### «Состояние компонентов»

程序会自动检查缺少它机器人就无法工作的必要组件。每次进入页面时都会在后台进行检查。在检查进行时，会显示“检查中...”。

- :smartphone: **ADB** — 电脑在手机上进行点击的服务。应当显示“已找到”。
- :monitor: **scrcpy** — 在电脑窗口中显示手机屏幕的程序。应当显示“已找到”。
- :image: **模板库** — 按钮和泰坦的“示例图片”，机器人据此识别屏幕上的内容。应当显示“已加载”。

如果某个项显示为红色该怎么办：

- **ADB 或 scrcpy 显示“未找到”。** 这意味着包含它们的文件夹未添加到 `PATH`（Windows 查找程序的路径列表）中。操作方法见[“所需准备与安装”](#2)一节。修改 `PATH` 后，关闭程序并重新打开：已经在运行的程序看不到新的 `PATH`。
- **模板库显示“未找到”。** 程序文件夹中缺少文件。最常见的情况是压缩包未完全解压，或者被杀毒软件删除了。将压缩包重新解压到新文件夹中，并按更新时的方法迁移 `profile.yml` 和 `bot_data`。

### Что лежит в папке бота и что нельзя удалять

点击“机器人文件夹”按钮打开它。那里有很多文件，但你只需要其中的几个。其余的是系统文件，程序运行需要它们。

- :file-text: `HeroWarsBot.exe` — 程序本身。机器人也从中运行，没有独立的程序文件。旁边的所有其他文件和文件夹（`guide`、`ui`、库、扩展名为 `.dll` 的文件等） headquarters 是程序的一部分。**切勿删除或重命名其中的任何内容**，否则它将无法启动。
- :file-text: `profile.yml` — 你的设置：会话目标、阈值、Telegram。**其中包含你的 Telegram 机器人的 Token，因此切勿将其发送给任何人。** 首次点击“保存设置”后生成。
- :folder: `bot_data` — 程序和机器人自行记录的所有内容。这是你拥有的**最宝贵的东西**。内部包含：
  - `stats.json` — 统计数据（“统计”页面）；
  - `rules` 文件夹 — 你的阵容和规则，包括机器人记住的规则；
  - `logs` 文件夹 — 战斗历史和机器人日志（`bot_log_...txt`）；
  - `debug` 文件夹 — 用于排查问题的截图（SOS 窗口、卡住、撤回失败）；
  - `titan_state.json` — 游戏日内泰坦的生命值和能量；
  - `profile.yml.bak` — 设置备份。“规则大师”中的“恢复 / 重置”利用它工作。**其中也包含 Telegram Token**；
  - `ui_settings.json` — 选定的窗口语言；
  - `sos_info.json`、`temp_sos.png`、`temp_test.png` — 用于 Telegram 消息的辅助临时文件。
- :pause: `pause.flag` — “暂停标志”。当机器人处于软暂停状态时出现。如果是上次留下的，程序启动时会自动将其删除。

> [!warning] **请勿删除或重命名** `profile.yml` 和 `bot_data`。如果删除了 `bot_data` — 统计数据、阵容、规则以及机器人学会的所有内容都将丢失。如果非常需要释放空间，可以清理 `bot_data/debug` 的内容以及 `bot_data/logs` 中的旧日志。但是机器人本身仅保留最新的 20 个日志和最新的 50 张截图，因此空间通常不是问题。

> [!tip] **每周备份一次。** 将 `profile.yml` 和 `bot_data` 文件夹复制到 U 盘或云端。如果电脑损坏或重新安装 Windows，你可以重新下载程序，并从副本中恢复阵容和统计数据。副本中包含 Telegram Token — 请妥善保管，切勿存放在共享文件夹中。
